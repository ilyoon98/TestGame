## 1. 한 줄 요약

**귀여운 이세계 동물원 방치형 타이쿤 + 위에서 내려다보는 도구 포획.**
포획 → (수송·보호소) → 사육장 배치 → 사육사 교대로 수익 → 시설·인력·도구에 투자.

## 2. 문서별 핵심 (확정된 사용자 방향만)

| 문서 | 확정된 방향 |
|---|---|
| 01 전체 | 모바일 가로 3D, 수익 방치형 + 직접 포획, 일반/몬스터/에픽 수집, 습격 대신 돌발 이벤트 |
| 02 개체 | 모든 개체 HP 보유, **HP 0 = 포획 완료**, 에픽은 고난도 + 동물원 전체 효과, 특화 사육사는 호감도·골드 보너스 |
| 03 시설 | 환경 적합 + 수용량 제약, 관리 공백 30% / 일반 100% / 우수 +n%, 직접 관리 가능 |
| 04 사육사 | 자동 근무·휴식, 누적 피로는 평소 휴식으로 다 풀리지 않음, 초기 고용 최대 2명, 직원당 담당 한도 |
| 05 포획 | 먹이(유인)·마취총(n초 기절)·덫(HP 감소)·포획끈(견인), 깨어나면 도주, 동굴·깊은 물 진입 시 놓침, 탐험 종료는 수송량 기준 |
| 06 수송·보호소 | 수송량 제한, 보호소는 기간 제한 임시 보관(예시 12시간 후 자동 탈출), 수용량 확장, 분양으로 재화 전환 |
| 07 경제 | 관리 공백 −70% 고정, 나머지 수치는 모두 임시 |

## 3. 게임 제작 전에 보완이 필요한 부분 (중요도 순)

기획서 자체가 "미결정"으로 남긴 항목 중 **규칙이 없으면 게임이 돌아가지 않는 것**부터 정리했습니다.
아래 결정은 모두 **프로토타입용 가정**이며, 플레이해 보고 바꾸면 됩니다.

### 3-1. 포획 완료 조건 (05-06, 01-11) — 가장 시급
- 문제: "HP 0 완료"와 "견인 거리/지정 위치 도착"이 두 개의 완료 조건으로 겹쳐 있음.
- **보완안: 완료 조건은 HP 0 하나뿐.** 견인 거리는 HP를 깎는 수단, 수송 트럭은 방향 안내일 뿐 필수 도착점 아님.
- 덫만으로는 끝낼 수 없음: 덫은 HP를 최소 1까지만 깎음 → 마지막은 반드시 포획끈으로 견인. (포획끈의 존재 이유 확보)
- 동시 발생 우선순위: **HP 0 > 탈출 지점 진입 > 깨어남**. 완료 판정은 개체당 1회만.
- 재마취: 같은 개체에 쏠 때마다 기절 시간 ×0.7 (무한 기절 방지).
- 끈이 끊기거나 놓쳐도 HP는 회복되지 않음(이번 탐험 한정). 탈출 개체는 이번 탐험에서 재등장하지 않음.

### 3-2. 피로·과로·사직 (04-06, 04-11) — 규칙 충돌 해소
- 문제: "피로 MAX 24시간 방치 시 퇴사"와 "정상 휴식으로 MAX가 풀림"이 충돌.
- **보완안: 지표를 둘로 분리하고 사직은 과로에만 연결.**
  - **피로**: 근무 시 +8/h, 휴게실 침상에서 −12/h, 침상 부족 시 −4/h. 100이 되면 교대 전이라도 강제 휴식(→ 관리 공백).
  - **과로**: 한 교대에서 8시간을 넘긴 근무 1시간마다 +5. 평소 휴식으로는 줄지 않음.
    → 2교대(12h)면 하루 +20, **5일이면 MAX** / 3교대(8h)면 쌓이지 않음 (04-07 의도 그대로).
  - **과로 MAX → 사직 대기 24시간**. 그 안에 **휴가(24시간 이탈, 과로 0으로 초기화)**를 보내면 해제, 아니면 퇴사.
  - 상위 휴게실(Lv2)은 침상 휴식 중 과로를 −1/h 회복 (07-09 "문제 해결이 가능한가"에 대한 두 번째 수단).

### 3-3. 보호소 타이머 (06-07, 01-11)
- **보완안**: 입소 시점부터 12시간, 개체에 "남은 시간"을 저장 → 사육장 배치 시 정지, 재입소 시 이어서 적용(초기화 없음).
- 같은 순간 배치와 만료가 겹치면 **플레이어 행동이 먼저** 처리.
- 만료 시 보유 목록에서 제거, 도감 기록 유지, 분양금 없음.

### 3-4. 보너스 중첩 규칙 (07-04, 02-07)
- **보완안**: 사육장 시간당 수익 = Σ기본수익 × (관리 배율 + 에픽 보너스 + 이벤트 보너스) — 합연산.
  - 관리 배율: 공백 0.3 / 일반 1.0 / 특화 사육사 담당 1.2
  - 에픽 효과는 **적합 사육장에 실제 배치된 동안만**, 같은 효과는 중첩 없이 최댓값 1개.
  - 보호소 보관 중에는 수익·에픽 효과 없음 (06-09 그대로).

### 3-5. 교대 구조와 담당 한도 (04-03, 04-09)
- 기획서에 "사육장별 담당자/교대자 지정"과 "직원당 1~n개 담당"만 있고 매칭 규칙이 없음.
- **보완안**: 교대 방식(2교대/3교대)을 동물원 전체에 하나로 설정. 직원은 교대 조에 자동 분배.
  현재 근무 중 직원은 각자 최대 2개 사육장을 담당하고, 특화 환경 사육장을 먼저 맡음.
  담당되지 못한 사육장 = 관리 공백(30%).
- 직접 관리: 공백 사육장에 "직접 돌봄" → 2시간 동안 일반 관리(100%). (03-07 "유지시간 미정" 보완)

### 3-6. 급여 부족 (04-10)
- **보완안**: 급여는 직원별 24시간마다 자동 지급, 잔고가 모자라도 지급(마이너스 잔고). 잔고가 음수인 동안 구매·고용·탐험 불가.
  (사직까지 연결하지 않음 — 사직은 과로 하나로만 유지해 원인을 명확히.)

### 3-7. 정산 보류와 시간 흐름 (06-04, 06-10)
- **보완안**: 귀환 정산 창을 닫으려면 모든 개체를 배치/보관/분양해야 함. 정산 중에도 동물원 시간은 흐름.
- 탐험 중에도 동물원 시간은 흐르되 1/5 속도 (현장 몇 분이 몇 시간이 되지 않도록).

## 4. 프로토타입 임시 수치

| 항목 | 값 |
|---|---|
| 시간 | 동물원 1게임시간 = 실제 2초(×1), ×5·×20 배속, 탐험 중 1게임시간 = 10초 |
| 시작 | 300골드, 초원 사육장 1개(수용 3), 사육사 2명(2교대), 침상 1, 고용 상한 2 |
| 수송 / 보호소 | 3마리 / 5마리(→10→20), 체류 12시간 |
| 급여 | 일반 50/일, 특화 70/일, 고용비 120 |
| 포획 | 마취 기본 6초 / 강한 저항 4초 / 에픽 3.5초, 재마취 ×0.7, 먹는 중 맞히면 ×1.5, 덫 30피해, 끈 1m당 HP 10(강화 15·22), 내구도 100(강화 160·250) |
| 깨어난 채 견인 | 속도 ×0.45 (강한 저항 ×0.25), 끈 내구도 −15/초 (강한 저항 ×2, 에픽 ×1.5) |
| 에픽 | 불씨 드래곤 HP 300, 배치 시 전체 수익 +15% |
| 분양가 | 기본 시간당 수익 × 12 (에픽 ×3) |
| 소모품 | 마취탄 10, 덫 20, 먹이 5 |
| 부지 | 사육장 최대 8칸 (부지 확장은 미구현 — 03-06 "부지 확장" 자리) |
| 돌발 이벤트 | 단체 관광객: 3시간 동안 개체 2마리 이상 사육장 수익 +50% |

## 5. 프로토타입 시뮬레이션으로 발견한 것

1. **견인 목적지에서 막힘** — "트럭 방향 견인"으로 트럭에 도착하면 더 움직이지 않아 HP가 줄지 않고, 드래곤이 HP 44에서 영원히 포획되지 않았음.
   → 트럭 원 안에서는 "우리로 끌어넣기"로 HP가 계속 감소하도록 수정. **견인 거리 기반 HP 감소를 채택하면 도착 지점 처리를 반드시 같이 정해야 함** (05-06 결정 시 참고).
2. **도구 역할 분화 부족** — 초기 수치에선 에픽을 제외한 전 개체가 마취 1발+끈으로 2~5초에 포획되어 덫·먹이를 쓸 이유가 없었음 (05-14 검증 항목).
   → 강한 저항 개체 기절 단축, 깨어난 뒤 견인 약화, 먹이 중 기절 ×1.5 적용 후: 이끼곰 덫 없이 6.3초 → 덫 사용 3.7초, 드래곤 마취 3발 → 먹이+덫 2발.
3. **2교대 과로 루프** — 설계 의도대로 2교대는 5일째 과로 MAX, 6~7일째 연속 퇴사. 단, 사육장 1개(3마리)만으로 하루 순수익 약 +300이라 고용 상한 증축+고용(약 420골드)은 1~2일이면 해결됨 → 실시간 기준이라면 압박이 약할 수 있음.
4. 보호소 남은 시간 유지(재입소 시 이어짐), 휴가로 사직 대기 해제, 만료 탈출 후 도감 유지 — 모두 의도대로 동작 확인.

## 6. 기획 쪽에 남기는 질문 (프로토타입으로는 결정할 수 없는 것)

1. 실제 시간 기준: 보호소 12시간·교대 12시간이 실시간이라면 하루 몇 번 접속을 가정하는가?
2. 에픽 효과 종류: 전체 수익% 외에 어떤 효과들이 있는가? (프로토타입은 "전체 수익 +15%" 하나)
3. 호감도: 프로토타입에서는 제외. 수익·연출·도감 중 무엇에 보상할지 결정 필요.
4. 계정 레벨과 재화 구매의 결합 방식(03-06): 프로토타입은 순수 골드 구매만.
5. 탈출한 보호소 개체의 재포획 이벤트 여부(06-08).
