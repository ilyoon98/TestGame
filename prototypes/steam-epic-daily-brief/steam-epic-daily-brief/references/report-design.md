# Steam 브리핑 디자인

사용자가 요청한 결과는 게임을 고르기 쉬운 한국어 보고서다. 상단은 제목·조사 기준 시각(KST)·장르 탭·유형 필터만 표시한다. 큰 할인·마감 요약과 하이라이트 목록은 출력하지 않는다. 대한민국 지역·성인등급 포함 여부·조사 제한은 접힌 조사 기준에 남기고 반복 안내와 추천 수식어를 줄인다.

정기 보고는 선택 화면 없이 14개 장르·유형별로 바로 제공한다. 장르 목록과 분량은 `SKILL.md`를 따른다. JSON의 `groups` 배열에 각 `{name, free, new, deals, emptyMessages}`를 넣으면 미리보기가 장르별 구역과 그 안의 무료·신작·할인을 만든다. 최상위 `asOf`, `genres`, `includeMature`, `highlights`, `limits`, `sources`는 유지한다. 게임 데이터 필드는 기존과 같다. 동일 앱 ID는 대표 장르의 한 행에만 넣고 관련 장르·출시·할인·무료 혜택은 그 행에 합쳐 적는다. 각 구역의 `emptyMessages`에는 확인한 범위에서 해당 없음과 접근 실패를 구분해 쓴다. `groups`가 없는 과거 JSON은 기존 유형별 구성을 유지한다. 특정 장르 추가 조사는 정기 보고 범위를 바꾸지 않는다.

상단에는 `전체`와 14개 장르 탭을 고정하고 바로 아래에 `전체·신작·할인·무료 배포` 유형 필터를 둔다. 두 조건은 교차 적용되며 장르를 바꿔도 유형 선택은 유지한다. 이미 조사한 결과를 필터링하는 기능으로, 재조사나 선택 제출 단계가 아니다. 출시 할인 중인 신작은 신작과 할인 양쪽 필터에서 보여 주되 전체 보기에서 중복하지 않는다. 정가 신작을 할인에 포함하지 않고, 무료 배포는 검증한 무료 소장 항목만 사용한다. 결과가 없을 때만 해당 조건의 빈 상태를 한 번 표시하고 접근 실패를 배포 없음과 구분한다. 요약 배너·반복되는 유형별 소제목·상시 빈 상태 안내는 넣지 않는다. 선택한 탭·게임 수를 표시하고 장르 탭의 방향키·Home·End 이동을 지원한다. 장르와 유형은 배경 상자 없는 텍스트·밑줄형 탭으로 표시한다. 선택한 항목만 파란 글자와 얇은 밑줄로 강조한다. 현재 보고서 화면에서 전체 장르가 가로 스크롤 없이 한 줄에 보이도록 글자와 간격을 조절한다. 좁은 폭에서는 로그라이크·로그라이트 → 로그라이크, 시뮬레이션·경영 → 시뮬·경영, 플랫포머·메트로배니아 → 플랫폼, 덱빌딩·자동 전투 → 덱·자동전투로 축약하되 전체 명칭을 툴팁과 접근성 이름에 유지한다. 넓은 화면에서는 전체 명칭을 표시한다. 카드·알약형 탭이나 넘겨야 하는 장르 목록으로 바꾸지 않는다. 게임명·짧은 설명·한국어·평가·정가·할인가·할인율·종료는 바로 보이고, 추가 장르·세부 참고사항은 `추가 정보`에서 펼친다. 화면 구성을 바꾸는 요청에서는 기존 조사 기준 시각과 검증한 가격을 유지한다.

현재 사용자는 **게임마다 Steam 공식 썸네일 표시**를 원한다. 상품 페이지나 공개 스토어 데이터에서 실제 `capsule_image`(보통 231×87) 또는 `header_image` 주소를 확인해 게임의 `thumbnailUrl`에 넣는다. 한국어 캡슐이 실제 제공되면 우선한다. URL을 임의로 조립하지 않는다. 이미지를 클릭하면 같은 게임의 공식 상품 페이지가 열리게 하고 alt 텍스트에 게임명을 넣는다. 이미지를 확인하지 못하거나 노골적인 성적 이미지밖에 없으면 썸네일은 생략하되 텍스트 상품 정보를 유지한다.

성인등급 포함 시에는 장르 탭 뒤에 `성인 게임` 모아보기를 추가한다. 좁은 폭의 표시는 `성인`이고 툴팁·접근성 이름은 전체 명칭이다. `mature: true`는 확인한 공식 성인등급, `matureContent: true`는 확인한 공식 성인 콘텐츠 안내를 뜻한다. 둘 중 하나가 참인 기존 게임 행을 필터링하며 장르 구역이나 이미지 행을 복제하지 않는다. 성인 탭에서도 전체·신작·할인·무료 배포를 고를 수 있고 일반 장르로 돌아가도 선택한 유형은 유지한다. 전체+14개 장르+성인 탭이 스크롤 없이 한 줄에 표시되는지 확인한다. 성인 탭이 성적 콘텐츠 전용 분류라고 추정하지 않는다.

**썸네일만 모은 별도 갤러리를 만들지 않는다.** 게임 한 개의 썸네일·이름·정가→할인가·할인율·한 줄 설명·출시 상태·마감·한국어·평가를 같은 행 또는 같은 정보 블록에 함께 표시한다. 기본은 왼쪽 `게임·썸네일`, 오른쪽 `가격·설명`의 2열 표다. 오른쪽은 게임명 → 가격·할인율 → 설명 → 상태·마감·한국어·평가 순서로 읽히게 한다. 이미지가 로딩되지 않더라도 오른쪽 가격과 설명은 남아 있어야 한다. 출시 전이라 가격이 없으면 미공개로 표시한다. 원래 보고서에 있던 가격과 설명을 빠뜨린 채 썸네일·게임명만 재출력하지 않는다.

현재 채팅에서는 공식 이미지 URL이 HTTP 200이어도 Markdown 썸네일 일부가 표시되지 않았다. **썸네일이 있는 결과는 일반 브라우저의 보고서 미리보기를 우선한다.** [preview_report.py](../scripts/preview_report.py)는 검증한 JSON과 [미리보기 템플릿](../assets/report-preview.html)으로 완성된 HTML을 만들고, `--serve`를 주면 해당 보고서만 localhost에 제공한다. 게임별로 썸네일·설명·가격을 한 행에 배치하고 좁은 화면에서는 세로로 재배치한다. 이미지 로드 실패 시 같은 게임의 다른 공식 이미지로 전환하고, 모두 실패하면 연결 실패 안내와 다시 불러오기 버튼을 제공한다. 이미지 로드 상태는 `complete`와 `naturalWidth`로 집계한다. HTTP 응답만으로 화면 표시를 확인했다고 말하지 않는다.

실행 예: `python scripts/preview_report.py <검증한-보고서.json> <출력-보고서.html> --serve`. 현재 채팅의 쓰기 가능한 출력 폴더를 사용하고 반환된 `REPORT_URL`을 `open_in_codex`의 browser 대상으로 연다. 브라우저로 실제 이미지·가격·설명이 표시되는지 확인한 뒤 사용자에게 링크를 제공한다. 표시 목적의 HTML 생성은 보고서 출력이며 별도 가격 이력 수집을 의미하지 않는다. 브라우저를 쓸 수 없으면 [render_markdown.py](../scripts/render_markdown.py)의 2열 Markdown 표와 공식 링크로 전달하고 이미지 표시 한계를 밝힌다.

Steam CDN 이미지는 인라인 visualize 시각화의 허용 출처에 포함되지 않으므로 이 미리보기는 **일반 브라우저 HTML**로 연다. 인라인 시각화의 출처 제한을 변경하거나 이미지를 다운로드해 data URL·다른 출처로 바꾸지 않는다. 일반 브라우저가 Steam 공식 CDN에서 이미지를 직접 로드하며 프록시는 만들지 않는다. 공식 스토어 응답의 실제 캡슐 주소를 `thumbnailUrl`에 넣고 같은 게임의 `header_image`, `capsule_imagev5` 등 확인한 대안 주소를 `thumbnailAlternates` 배열에 넣는다. 앱 ID가 다른 이미지나 검토하지 않은 노골적인 성적 이미지는 넣지 않는다. 미리보기 스크립트는 공식 Steam CDN과 동일 앱 ID의 경로만 허용한다. 이미지를 확인할 수 없으면 해당 URL을 비워 두고 텍스트 정보는 유지한다.

썸네일이 필요 없는 결과에 시각화를 사용할 때는 `visualize` 스킬을 읽고 검증한 게임 데이터를 직접 넣은 날짜별 HTML 조각을 채팅 안에 보여준다. 자료 조사는 먼저 완료하고 결과를 렌더링한다. 화면 자체에서 네트워크 조회를 하지 않는다. 선택 화면과 결과 보고서는 각각의 역할에 맞게 만든다.

기본 레이아웃은 [보고서 템플릿](../assets/report.html)을 복사해 사용한다. `steam-daily-report-data` JSON의 `asOf`(KST 날짜·시각), `genres`, `includeMature`, `highlights`, `free`, `new`, `deals`, `emptyMessages`, `limits`, `sources`를 확인한 자료로 채운다. 게임 항목은 `title`, `url`, `description`, `genre`, `korean`, `rating`, `mature`, `status`, `note`, `originalPrice`, `price`, `discount`, `deadline` 필드를 사용하며 모르는 값은 비워 두거나 미확인으로 적는다. 출처는 `label`, `url` 쌍이다. JSON 삽입 시 `<`를 `\u003c`로 이스케이프해 script 태그 종료와 섞이지 않게 한다. 가격·무료 여부·기한은 표시용 문자열도 검증 결과에서 작성한다. 빈 항목은 조사 성공 후 해당 없음인지 접근 실패인지 `emptyMessages`에 명시한다. 빈 템플릿 자체를 실제 조사 결과로 표시하지 않는다.

- 정기 보고는 장르별 구역을 만들고 각 장르 안에서 무료 배포 → 신작 → 할인 순서를 유지한다. 각 부분은 여백과 절제된 구분선으로 나누고, 게임명은 공식 상품 링크로 연결한다.
- 가격을 가장 먼저 읽히게 배치하고 할인율, 정가, 종료 기한을 그 옆에 정렬한다. `무료 소장`, `출시 예정`, `앞서 해보기`, `24시간 이내 마감`, `성인등급`은 실제 확인된 경우에만 짧은 상태 표시로 붙인다. 장르·한국어 지원은 보조 정보다.
- 게임마다 한 줄 특징과 추천 이유를 제공한다. 많은 정보를 채우는 것보다 가격·마감·선정 근거가 읽히는 구성을 우선한다. 의미 없는 점수·순위·장식용 통계는 만들지 않는다.
- 밝은/어두운 테마와 좁은 화면에 대응하고, 링크와 원화 숫자의 대비를 확보한다. 표가 길어지면 세부 정보를 펼쳐 보게 하거나 게임별 행으로 나누며 불필요한 카드 중첩은 피한다.
- 자료를 정렬·비교할 때는 장르 필터에 맞는 검증 항목만 사용한다. 확인 가능한 Steam 썸네일을 게임별로 함께 표시하되 성적으로 노골적인 이미지나 설명은 포함하지 않는다.
- 마지막에는 가격 출처, 정확한 마감 시각 미확인, 접근 제한 등 판단에 필요한 확인 범위만 짧게 남긴다.

시각화를 표시할 수 없거나 사용자가 표를 요청하면 같은 정보 우선순위를 유지한 Markdown 표로 전달한다. 인터랙티브 보고서를 표시한 뒤 동일한 표와 장문 설명을 채팅에 중복하지 않는다. 게임 데이터가 없으면 예시 가격을 만들어 디자인을 채우지 않는다.
