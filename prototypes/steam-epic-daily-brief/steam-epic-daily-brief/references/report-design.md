# Steam 브리핑 디자인

## 화면과 탐색

Steam 스토어에 가까운 남색·청회색 계열을 사용한다. 예시 토큰은 배경 #182a38, 패널 #1b3041, 왼쪽 목록 #132735, 본문 #e4edf4, 보조 #99b1c2, 선택 파랑 #66c0f4, 할인 배경 #4c6b22·글자 #c6f279다. 많은 색상 배지를 쓰기보다 가격과 할인만 가장 강하게 읽히게 한다.

상단은 제목·실제 조사 기준 시각만 둔다. 왼쪽 약 190px에는 장르 세로 목록과 태그 체크박스를, 오른쪽에는 전체/신작/할인/무료 탭과 목록을 둔다. 무료 탭 안에서 100% 할인·영구 소장과 상시 무료를 전환한다. 왼쪽 장르 선택은 파란 행으로 표시한다. 작은 글씨의 가로 한 줄 탭은 사용하지 않는다. 좁은 화면에서는 장르·태그 버튼으로 탐색을 펼친다. 큰 할인 요약·하이라이트·반복 안내는 넣지 않는다.

장르는 하나씩 선택하며 태그는 여러 개 선택해 모두 포함(AND)하는 게임을 표시한다. 장르·유형·태그를 교차 적용한다. 태그 검색 입력창은 제공하지 않는다. 실제 조사 데이터의 `steamTags`로 후보를 만들고 현재 장르·유형에서 태그별 수를 계산한다. 현재 범위의 태그는 6개까지 표시하고 선택한 태그는 유지한다. 인디는 검증한 `isIndie`도 근거로 사용할 수 있지만 사용자 태그와 공식 장르의 차이는 툴팁에 밝힌다. 선택 태그 해제·초기화를 제공하고 0개 선택은 제한 없음이다. 필터는 이번 보고서 보기만 바꾸며 정기 조사 범위는 바꾸지 않는다.

카드의 태그 버튼은 왼쪽 체크박스와 같은 필터를 켜고 끈다. `한국어 O` 버튼은 한국어 지원이 확인된 게임만 표시한다. 두 필터 모두 현재 장르·유형에 적용되며 목록 위에서 각각 해제할 수 있다. 리뷰 수와 평가는 해당 게임의 Steam 리뷰 구역(`#app_reviews_hash`)으로 연결한다.

왼쪽 장르 목록의 `협동`은 Steam 협동(1685), 온라인 협동(3843), 로컬 협동(3841), 협동 캠페인(4508) 태그가 확인된 게임을 장르를 넘어 모아 보여 준다. 기존 카드에 필터를 적용하므로 게임을 복제하지 않는다. `전체` 탭의 `NEW만` 버튼은 실제 NEW 리본이 있는 카드만 표시하며 왼쪽 장르·태그·한국어 필터와 함께 적용된다.

## 게임 목록

장르별 신작 3개·할인 3개를 별도로 선정하며 무료 소장은 별도다. 신작과 할인은 각각 제목이 있는 구역으로 나누고 각 구역 안에서 큰 이미지 카탈로그를 만든다. 넓은 화면 3열, 중간 2열, 좁은 화면 1열을 사용한다. 전체 보기의 같은 앱 ID는 대표 장르에 한 번만 렌더링한다. 유형 필터로 옮긴 게임은 전체 보기에서 원래 구역으로 복원하며 행을 복제하지 않는다. `selectionLimits:{new:3,deals:3}`는 유형 필터에도 적용하고 할인 탭은 장르 안에서 마감이 가까운 순으로 표시한다. 마감이 확인되지 않은 항목은 뒤에 둔다.

게임 한 개는 **큰 이미지 → 제목 → 할인율·정가·현재 가격 → 설명 → 한국어·리뷰 → 태그** 순서다. 가격은 23px 안팎의 가장 큰 굵은 숫자다. 할인율은 가격 바로 옆 녹색 블록에 한 번만 표시한다. 원래 가격은 작고 흐린 취소선이다. 가격을 설명·태그 아래에 놓지 않는다. 실제 마감만 가격 아래 짧은 문구로 적고 24시간 이내·3일 이내·7일 이내 중 가장 가까운 구간을 붙인다. 24시간 이내는 텍스트 색으로 강조한다.

게임명은 공식 명칭 그대로 한 줄 말줄임하고 전체 이름을 툴팁으로 제공한다. 설명은 짧은 한국어 1~2줄이며 전체 설명은 툴팁에 보존한다. 신작·앞서 해보기·출시 예정은 이미지 모서리의 작은 중립 라벨로 표시한다. `releaseDate`는 툴팁에만 넣고 오래된 일반 출시작의 날짜·일반 출시 라벨은 생략한다.

한국어 O는 초록 체크·텍스트로 강조하고 X·미확인은 중립 텍스트로 둔다. 리뷰 수와 평가는 나란히 읽히는 보조 텍스트다. 한국어·리뷰·태그마다 배경 상자를 만들지 않는다. `reviewCount`는 정수이며 500/1,000/5,000/10,000/50,000/100,000 단계(이하는 실제 수)를 쓴다. 최근 30일 자료는 최근 리뷰로 표시하고 `reviewSummary`는 같은 범위의 Steam 원래 평가 이름이다. 정확한 수·긍정률·기간·언어 범위는 툴팁으로 제공한다. 평가 없음과 미확인을 구별한다.

카드에는 핵심 태그를 최대 2개 표시한다. 확인한 성적·노출 태그를 우선하며 전체 태그는 Steam 상품 페이지에서 볼 수 있다. `primaryTags`는 실제 `steamTags`에 있는 이름만 사용한다. 불필요한 추가 정보와 Steam 사용자 태그와 한국 지역 본편 가격을 확인했습니다 같은 문구는 출력하지 않는다. 꼭 필요한 실제 구매 조건만 `purchaseNote`에 둔다.

## 데이터와 이미지

정기 보고 데이터는 `groups:[{name,free,alwaysFree,new,deals,emptyMessages}]`와 `asOf`, `genres`, `includeMature`, `limits`, `sources`, `selectionLimits`를 쓴다. `free`에는 100% 할인 영구 소장 본편을 `freeType:"keep"`으로, `alwaysFree`에는 상시 무료 본편을 `freeType:"always"`로 기록한다. 둘 다 `priceVerified:true, priceValue:0`을 쓰고 영구 소장은 `discountPercent:100`과 확인된 마감도 기록한다. 상시 무료 신작은 `freeType:"always"`로 `new`에 한 번만 기록해도 두 탭에 표시된다. 필드 값은 이번 실행에서 공식 출처로 확인하며 가격·무료 배포·기한을 예시 값으로 채우지 않는다. 형식만 바꾸면 기존 가격과 조사 시각을 보존한다. 신규 조사로 바뀐 부분은 별도 확인 시각을 기록한다.

큰 이미지는 상품 페이지나 공식 공개 스토어 데이터에서 확인한 `header_image` 등 실제 URL을 `thumbnailWideUrl`에 넣고 기존 캡슐은 `thumbnailUrl`, 확인한 다른 이미지는 `thumbnailAlternates`에 둔다. 없는 주소를 조립하지 않는다. `thumbnailWideUrl`이 없으면 기존 이미지로 표시한다. 공식 Steam CDN·같은 앱 ID 경로만 허용하며 실패하면 같은 게임의 다른 공식 이미지·재시도 버튼을 사용하고 가격·설명은 유지한다. 이미지와 게임명을 누르면 해당 공식 상품 페이지가 열린다. 노골적인 성적 이미지·설명은 전재하지 않는다.

썸네일 보고서는 [브라우저 템플릿](../assets/report-preview.html)과 [preview_report.py](../scripts/preview_report.py)로 검증한 JSON을 단일 HTML에 담는다. 일반 브라우저에서 파일을 직접 열면 서버 없이 탭과 필터를 쓸 수 있다. 정기 실행은 날짜별 HTML에 더해 `--latest <보고서 폴더>/latest.html`로 같은 내용을 고정 경로에 쓴다. 채팅에서 그 파일을 링크한다. `--serve`는 수동으로 로컬 미리보기가 필요할 때만 사용한다.

이미지와 영상은 브라우저가 공식 Steam CDN에서 직접 로드하므로 인터넷이 필요하다. 인라인 시각화 출처 제한을 바꾸거나 이미지를 다운로드·data URL·프록시로 바꿔 우회하지 않는다. 실제 표시·재생을 확인한 범위만 보고하고 실패·누락을 확인 범위 내 해당 없음과 구분한다.

이전 날짜의 같은 범위 JSON이 있으면 `--previous 이전.json`을 추가한다. 첫 화면에는 확인한 전체 목록을 표시하며, 각 장르의 신작·할인 구역에서 새로 소개한 게임, 가격·출시 상태 변경, 7일 이내 마감 할인을 먼저 배치한다. 할인 탭은 마감순이다. 비교 기준 날짜는 출처와 조사 기준에서 확인할 수 있다. JSON은 다음 실행의 비교 기준으로 쓸 수 있다.

이전 보고서에 없던 항목이나 검증된 가격·할인율·출시 정보·마감 기한이 달라진 항목에만 썸네일 오른쪽 위 대각선 `NEW` 리본을 표시한다. 단순히 마감이 가까워진 항목에는 리본을 붙이지 않는다. 왼쪽 위 신작·앞서 해보기 라벨은 출시 상태를 표시한다. 리본과 이미지 링크의 접근성 이름·툴팁에서 갱신 이유를 확인할 수 있다.

출처·지역·한계는 마지막에 접어서 제공한다. 브라우저 미리보기가 지원되지 않으면 [render_markdown.py](../scripts/render_markdown.py)의 공식 링크 표로 전달하며 인터랙티브 필터·이미지 표시 한계를 짧게 밝힌다. 같은 보고서를 채팅에 긴 표로 반복하지 않는다.

성인 요소는 일반 게임에서 실제 선정적 콘텐츠(12095)·신체 노출(6650) 사용자 태그가 확인된 경우만 모은다. 일반 성인등급·폭력·감성적 같은 유사 문자열은 근거가 아니다. 성인 전용 성적 콘텐츠 카탈로그로 소개하지 않고 관련 기본 기준은 SKILL.md를 따른다.


## 영상

확인한 공식 트레일러는 `videoSources:[{url,type}]`(video/mp4, video/webm, application/vnd.apple.mpegurl), `videoTrailerId`, `videoTitle`, `videoSourceUrl`로 기록한다. 마우스 오버 350ms 후 무음 재생하며 이탈·필터 변경·페이지 비활성화 시 정지한다. 모바일·키보드는 영상 버튼을 쓴다. 동작 줄이기 설정은 자동 재생을 끄되 명시적 재생은 허용한다. 동시에 하나만 재생하고 상호작용 전에는 영상 네트워크 요청을 하지 않는다. 재생이 시작될 때만 썸네일 위에 표시하고 실패 시 썸네일을 복원한다.

실제 확인한 주소만 사용하며 공식 Steam 영상 CDN과 같은 앱의 `/store_trailers/<appid>/` 또는 확인한 movie ID의 `/steam/apps/<movieid>/` 경로만 허용한다. HLS 주소에서 MP4 경로를 추측하지 않는다. 기본 HLS 지원을 우선하고 필요한 경우만 고정 버전 HLS.js 1.7.4를 무결성 값과 함께 로드한다. 공식 라이브러리 출처는 https://github.com/video-dev/hls.js/releases/tag/v1.7.4 이다. 영상 파일을 내려받거나 로컬에 제공하지 않고 브라우저가 공식 CDN에서 직접 재생한다.


## 현재 장르 구성

대표 장르는 19개이며 자동화·공장, 타워 디펜스, 도시 건설을 독립 항목으로 제공한다. 덱빌딩과 오토배틀러는 서로 다른 항목이다. 각 항목에 작은 아이콘과 분명한 이름을 표시하며 기존 왼쪽 세로 탐색·유형·태그 교차 필터를 유지한다. 현재 보고서는 복합 장르 항목을 생성하지 않는다. 과거 보고서의 덱빌딩·자동 전투 표기는 호환용으로 읽을 수 있으나 새 수동 선택 화면은 둘로 나누며 저장된 복합 선택을 두 장르 선택으로 이전한다.
