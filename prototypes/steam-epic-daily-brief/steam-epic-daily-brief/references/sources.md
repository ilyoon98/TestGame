# 출처와 접근 대안

## Steam

- 신작: https://store.steampowered.com/search/?sort_by=Released_DESC
- 할인: https://store.steampowered.com/specials/
- 할인 검색 대안: https://store.steampowered.com/search/?specials=1
- 공식 뉴스: https://store.steampowered.com/news/
- 개별 상품: 스토어 목록에서 실제 `https://store.steampowered.com/app/숫자/` 링크를 찾아 연다. 상품 ID를 임의로 만들지 않는다.

가능하면 URL에 `cc=kr`와 `l=koreana`를 사용한다. 이미 쿼리가 있으면 `&`로 추가한다. 이 매개변수만으로 KRW가 보장되지는 않으므로 반환된 페이지의 통화·지역을 확인한다. 한국 매개변수 URL이 열리지 않으면 기본 URL에서 후보를 찾고 개별 상품의 한국 지역 페이지를 확인한다.

출시일순 검색에는 DLC·데모·사운드트랙·프롤로그도 섞인다. 본편인지, 출시가 예정인지 완료인지 상품 페이지에서 확인한다. 출시 할인과 일반 할인을 구분하면 유용하다. 무료 주말은 기간이 끝나면 플레이 권한이 만료될 수 있으므로 공식 공지에서 소장 여부를 확인한다. 무료 소장 후보는 `site:store.steampowered.com` 또는 `site:steamcommunity.com`과 `free to keep`, `100% off`, `무료 배포` 등을 조합해 찾되 해당 기간과 상품을 다시 연다.

## 장르별 후보 찾기

성인등급 포함이 켜져 있으면 성인용 콘텐츠 안내가 있다는 이유만으로 제외하지 않는다. 공식 장르·등급과 비노골적 상품 정보를 확인한다. 연령 확인·로그인·지역·검색 환경설정 때문에 누락될 수 있으므로 공개 도메인 검색과 공식 공지로 보완하고, 끝내 확인되지 않는 부분은 제한으로 보고한다. 계정이나 스토어 설정을 임의로 바꾸거나 확인 절차를 우회하지 않는다.

장르가 선택되었으면 스토어의 실제 장르/태그 필터와 그 장르의 신작·할인 목록을 우선 탐색한다. 필요한 경우 한국어 장르명과 영문 동의어로 공식 도메인 검색을 보완한다. 장르별 탐색 링크는 현재 스토어에서 확인하고, 숫자 태그 ID나 URL 매개변수를 임의로 만들지 않는다. 전체 인기 목록 몇 개만 걸러낸 결과를 장르 조사 전체로 간주하지 않는다.

최종 선정할 때는 개별 상품의 분류·태그·플레이 설명을 확인한다. 무료 배포 목록도 먼저 확인한 다음 선택 장르에 맞는지 판정한다. 모든 신작·할인·배포 항목에 동일한 필터를 적용하되 사용자가 명시한 섹션별 예외를 우선한다. 복합 장르가 정확히 맞는지 불명확하면 그 근거와 불확실성을 밝히거나 선정에서 제외한다.

## 확인 실패를 다루는 예

- 목록이 영어·USD이고 한국 상품을 못 열었음 → 게임 소식은 근거가 있으면 소개하되 `한국 가격 미확인`.
- 무료 검색 목록이 누락되었음 → `기간 한정 무료 소장 목록 확인 불가`, 배포 없음으로 단정하지 않음.
- 무료 주말 종료 공지만 있음 → 기간 한정 플레이로 표시하고 무료 소장 표에는 넣지 않음.
- 종료일만 공식적으로 적혀 있음 → 날짜를 그대로 쓰고 시간 미공개 표시, 자정/정오 추정 금지.
- 게임명이 같지만 한쪽은 디럭스 에디션임 → 에디션을 구분해 표시하고 직접 최저가 비교하지 않음.
