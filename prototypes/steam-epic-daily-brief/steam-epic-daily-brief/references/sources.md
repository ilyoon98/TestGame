# 출처와 접근 대안

## Steam

- 신작: https://store.steampowered.com/search/?sort_by=Released_DESC
- 할인: https://store.steampowered.com/specials/
- 할인 검색 대안: https://store.steampowered.com/search/?specials=1
- 공식 뉴스: https://store.steampowered.com/news/
- 상시 무료 후보: https://store.steampowered.com/genre/Free%20to%20Play/
- 개별 상품: 스토어 목록에서 실제 `https://store.steampowered.com/app/숫자/` 링크를 찾아 연다. 상품 ID를 임의로 만들지 않는다.

가능하면 URL에 `cc=kr`와 `l=koreana`를 사용한다. 이미 쿼리가 있으면 `&`로 추가한다. 이 매개변수만으로 KRW가 보장되지는 않으므로 반환된 페이지의 통화·지역을 확인한다. 한국 매개변수 URL이 열리지 않으면 기본 URL에서 후보를 찾고 개별 상품의 한국 지역 페이지를 확인한다.

출시일순 검색에는 DLC·데모·사운드트랙·프롤로그도 섞인다. 본편인지, 출시가 예정인지 완료인지 상품 페이지에서 확인한다. 출시 할인과 일반 할인을 구분하면 유용하다. 무료 주말은 기간이 끝나면 플레이 권한이 만료될 수 있으므로 공식 공지에서 소장 여부를 확인한다. 무료 소장 후보는 `site:store.steampowered.com` 또는 `site:steamcommunity.com`과 `free to keep`, `100% off`, `무료 배포` 등을 조합해 찾되 해당 기간과 상품을 다시 연다.

## 장르별 후보 찾기

일반 장르에서 선정한 게임의 부수적 성적·노출 요소는 실제 사용자 태그로 표시한다. 성인 전용 성적 콘텐츠 카탈로그는 추천 후보로 수집하지 않는다. 연령 확인·로그인·지역 제한을 우회하지 않는다.

장르가 선택되었으면 스토어의 실제 장르/태그 필터와 그 장르의 신작·할인 목록을 우선 탐색한다. 필요한 경우 한국어 장르명과 영문 동의어로 공식 도메인 검색을 보완한다. 장르별 탐색 링크는 현재 스토어에서 확인하고, 숫자 태그 ID나 URL 매개변수를 임의로 만들지 않는다. 전체 인기 목록 몇 개만 걸러낸 결과를 장르 조사 전체로 간주하지 않는다.

최종 선정할 때는 개별 상품의 분류·태그·플레이 설명을 확인한다. 무료 배포 목록도 먼저 확인한 다음 선택 장르에 맞는지 판정한다. 모든 신작·할인·배포 항목에 동일한 필터를 적용하되 사용자가 명시한 섹션별 예외를 우선한다. 복합 장르가 정확히 맞는지 불명확하면 그 근거와 불확실성을 밝히거나 선정에서 제외한다.

## 확인 실패를 다루는 예

- 목록이 영어·USD이고 한국 상품을 못 열었음 → 게임 소식은 근거가 있으면 소개하되 `한국 가격 미확인`.
- 무료 검색 목록이 누락되었음 → `기간 한정 무료 소장 목록 확인 불가`, 배포 없음으로 단정하지 않음.
- 무료 주말 종료 공지만 있음 → 기간 한정 플레이로 표시하고 무료 소장 표에는 넣지 않음.
- 종료일만 공식적으로 적혀 있음 → 날짜를 그대로 쓰고 시간 미공개 표시, 자정/정오 추정 금지.
- 게임명이 같지만 한쪽은 디럭스 에디션임 → 에디션을 구분해 표시하고 직접 최저가 비교하지 않음.

## 성적 콘텐츠 태그 기준

성인 요소 탭은 일반 성인등급이 아닌 Steam 사용자 태그 기준이다. 현재 확인한 태그는 `선정적 콘텐츠`(Sexual Content, 12095), `신체 노출`(Nudity, 6650)이며 영어·한국어 표기는 같은 ID로 다룬다. 선정한 일반 게임의 상품 페이지 사용자 태그 또는 같은 태그로 필터링한 공식 결과의 앱 ID를 근거로 기록한다. API `genres`, `required_age`, `content_descriptors`를 사용자 태그로 바꿔 쓰지 않는다. 명시적 태그 ID/이름을 정확히 비교하고 `감성적`·`폭력`·`유혈`은 성적 콘텐츠의 근거가 아니다. 분류는 Steam 사용자 태그임을 밝히며 노골적인 설명과 이미지를 전재하지 않는다.


인디 후보는 장르 검색에 현재 Steam 태그 인디(ID 492)를 함께 적용해 보강하고 개별 본편을 검증한다. 공식 API 장르 인디(ID 23)도 근거로 사용할 수 있다. 사용자 태그와 공식 장르를 구별해 기록한다. 리뷰 API가 응답하지 않으면 공식 상품 페이지 평가 요약과 툴팁을 사용한다. 최근 30일·전체 기간·한국어 평가를 구분하고 수와 평가 이름을 같은 범위에서 추출한다.


## 증분 게임

인크리멘탈(Incremental) 태그의 현재 확인 ID는 560542다. 공식 신작·할인 검색에서 후보를 찾고 상품 설명의 자원 축적·업그레이드·자동화·초월 등 반복 성장 구조를 확인한다. 방치형과 겹칠 수 있지만 두 분류를 자동으로 동일시하지 않는다. 원래 장르와 증분 양쪽에 같은 앱을 복제하지 않고 대표 장르 한 곳에 배치한다. 중요한 장르 태그를 강조할 때 실제 사용자 태그와 공식 장르를 혼동하지 않는다.


## 자동화·공장 / 타워 디펜스 / 도시 건설 / 덱빌딩 / 오토배틀러

현재 확인한 사용자 태그 ID는 자동화 255534, 타워 디펜스 1645, 도시 건설 4328, 덱빌딩 32322, 오토 배틀러 1084988이다. 매 실행 때 공식 필터와 상품 설명을 확인한다. 자동화는 생산·가공·물류, 타워 디펜스는 배치·방어, 도시 건설은 정착지 운영, 덱빌딩은 덱 구성·변경, 오토배틀러는 전투 전 유닛·진형 구성과 자동 전투가 실제 핵심이어야 한다. 태그만 따라 분류해 단순 방치 수익·카드 제작·자동 사격 게임을 섞지 않는다. 덱빌딩과 오토배틀러는 별도로 조사하되 같은 게임은 대표 장르 한 곳에만 배치한다.
