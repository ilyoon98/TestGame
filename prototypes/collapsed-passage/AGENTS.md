# 붕괴 통로 UI 문구

- 화면에는 플레이 결정에 필요한 이름, 상태, 수치만 남긴다. 뜻이 분명하면 아이콘과 숫자로 보여주고, 아이콘의 자세한 뜻은 접근성 레이블과 도움말에 둔다.
- 실제 게임 UI에서 쓸 만한 짧고 자연스러운 한국어를 쓴다. 장황한 안내, 같은 내용의 반복, 상투적인 홍보 문구를 걷어내 AI가 작성한 티를 줄인다.

## 캐릭터 원화

- 새 인물을 만들기 전에 `index.html`의 `partyArt`에 연결된 기존 PNG를 직접 보고, 같은 소속의 원본 PNG를 이미지 생성 참조로 첨부한다. 아군의 V5 SD 비율, 선 굵기, 셀 채색, 시점과 발 기준선을 맞춘다.
- 얼굴·머리·복장·장비를 카드와 전투 포즈에도 이어간다. 적용 전에 기존 인물 옆에 두고 실제 게임 표시 크기에서 확인한다.
