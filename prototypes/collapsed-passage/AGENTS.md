# 루치아: 빈콜리의 등불 UI 문구

- 화면에는 플레이 결정에 필요한 이름, 상태, 수치만 남긴다. 뜻이 분명하면 아이콘과 숫자로 보여주고, 아이콘의 자세한 뜻은 접근성 레이블과 도움말에 둔다.
- 실제 게임 UI에서 쓸 만한 짧고 자연스러운 한국어를 쓴다. 장황한 안내, 같은 내용의 반복, 상투적인 홍보 문구를 걷어내 AI가 작성한 티를 줄인다.
- 영입은 이름·배지·선택과 시너지 변화로 표시한다. 판단에 필요한 카드 수치, 위치 제한, 교체할 동료 이름은 해당 선택 옆에 둔다. 행동 기록은 펼쳐서 본다.

## 캐릭터 원화

- 새 인물을 만들기 전에 `src/presentation/artData.js`의 `partyArt`에 연결된 기존 PNG를 직접 보고, 같은 소속의 원본 PNG를 이미지 생성 참조로 첨부한다. 아군의 V5 SD 비율, 선 굵기, 셀 채색, 시점과 발 기준선을 맞춘다.
- 얼굴·머리·복장·장비를 카드와 전투 포즈에도 이어간다. 적용 전에 기존 인물 옆에 두고 실제 게임 표시 크기에서 확인한다.

## 전투와 보상

- 가드는 부위별로 관리한다. 관통은 현재 타격에 적용하고 가드 제거는 대상 부위에서 차감한다.
- 자동 표적 선택과 실제 타격은 같은 피해 계산을 쓴다. 표적을 비교할 때 상태를 변경하지 않는다.
- 같은 시드와 상태로 보상을 재현한다. 가능한 후보가 있으면 현재 출전 상태에서 발동 가능한 신규 카드 한 장을 확보한다.

## 코드 구조

- 코드를 고치기 전에 `ARCHITECTURE.md`(계층과 의존 방향)와 `CLASSES.md`(클래스별 역할)를 읽고, 책임에 맞는 클래스에 고친다.
- 클래스를 추가하거나 책임을 옮기면 `CLASSES.md`를 함께 고친다.
- 게임 규칙(`src/domain/`)은 DOM·타이머·`Math.random`을 쓰지 않는다. 객체 생성은 `src/application/createGameServices.js`에서 한다.
