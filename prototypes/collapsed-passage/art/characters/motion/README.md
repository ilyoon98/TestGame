# 공격·피격 한 장씩

Darkest Dungeon 1처럼 한 행동에 한 장의 명확한 자세를 보여준다는 사용자 요청을 적용했다. 수녀·여성 간수·여성 개화 수감자·일반 적 5종에 각각 `*-attack.png`, `*-hit.png`가 있다. 총 16장의 실제 RGBA 투명 전신 이미지이며 연속 프레임은 없다. 원작 게임의 이미지를 사용하지 않았다.

## 런타임

`index.html`의 `motionArt`가 인물별 파일을 배정한다. 현재 전투의 수녀·생존 동료·적에 필요한 포즈만 미리 불러온다. 공격 시작에 공격자 포즈를 바꾸고 105ms 뒤 실제 피해가 있으면 피격자의 포즈도 바꾼다. 타격 뒤 470ms 유지하고 두 인물을 기본 자세로 복구한다. 완전 방어에서는 기본 자세를 유지하고 가드 수치로 알린다. 방어/회복 카드는 기존 수치·삽화 연출을 유지한다.

1·2·4배속을 적용하며 동작 줄이기에서는 105ms 선행 지연 없이 포즈를 바로 보여준다. 일시정지는 현재 행동을 마친 뒤 멈춘다. 반격·다음 행동·전투 종료 전에 복구하고 재시작/취소 시 남은 타이머와 포즈를 정리한다. 불러오는 중이거나 읽기 실패한 포즈는 기본 이미지를 유지한다.

## 제작과 검수

`find-skills`로 `skills.sh`와 `npx skills find "2d sprite animation"`을 확인했다. 이미 설치된 `2dimg2motion`의 원화 참조·키포즈 전체 재생성·손/무기 소유권 고정 작업 방식이 맞아 사용했으며 추가 설치는 하지 않았다. 해당 스킬의 기본 14프레임은 사용자가 요청한 공격/피격 각 1장으로 대체했다.

built-in `image_gen`으로 인물마다 두 자세를 같은 시트에서 생성했다. 수녀와 동료는 현재 적용된 V5 PNG, 적은 `index.html`의 기존 WebP를 기준으로 삼았다. 코드로 포즈나 팔다리를 그리지 않았다. 실제 투명 간격을 찾아 두 이미지를 분리한 뒤, 같은 인물의 두 자세에 동일한 등비 배율과 세로 오프셋을 적용했다. 가로 중심만 셀별로 등록해 다른 포즈 조각이 섞이거나 무기가 잘리지 않도록 했다. 원본 생성 시트는 생성 도구의 저장소에 보존했다.

[프롬프트 전문](PROMPTS.md) · [프레임·등록 메타데이터](manifest.json). 알파 ≥ 250의 발 위치 오차는 기준선에서 2px 이내다. 두 포즈를 나란히 놓은 합성 미리보기로 전신·머리·무기·손의 소유권·의상을 확인했다.

`tests/combat-presentation.test.mjs`가 16장 파일의 RGBA·투명도·해상도·여백·발 위치와 런타임 교체/복구를 검증한다. 전체 32개 테스트와 고정 난수 45판 자동 진행을 함께 확인했다. 실제 브라우저의 최종 배치와 모바일 조작은 로컬 파일 접근 제한으로 직접 검증하지 못했다.
