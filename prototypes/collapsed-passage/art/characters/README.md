# 적용된 V5 SD 캐릭터

V5 원화를 참조해 built-in `image_gen`으로 제작한 투명 전신 PNG를 게임에 연결했다. 수녀는 작은 검은 베일·얇은 흰 띠·흰 어깨천·등불·둥근 방패, 여성 간수는 붉은 포니테일·제복·진압봉·사각 방패, 여성 개화 수감자는 은발·붕대·짧은 사슬을 유지한다. 세 인물 모두 앞뒤 허리천과 불투명한 안쪽 짧은 바지를 사용한다.

## 연결 방식

- `index.html`의 `partyArt`에서 파일을 배정하고 `bodyAnchors`에 부위 위치를 둔다.
- 출전한 수녀·동료와 적이 전장에 나란히 선다. 수녀·간수·개화 수감자는 [공격·피격 키포즈](motion/README.md)를 사용한다. 궁수와 주술사는 기본 스프라이트로 전투 동작을 재생한다.
- 다섯 아군이 같은 2:3 캔버스와 발 기준선을 사용한다. 속사·치유 주문·봉인 해제에는 해당 대원의 수정된 얼굴과 장비가 나온다.
- 전장 인물 위 부위 점과 공격 연결선은 숨긴다. 세부 내구도·가드는 인물별 ‘부위 상태’를 펼쳐 확인한다. 펼친 상태는 다음 행동 렌더링에도 유지한다.
- 동료 교체 시 파일이 바뀌고 사망한 동료는 전장에서 사라진다. 조우 화면에서도 같은 인물 이미지를 사용한다.
- 게임 배포·복사 시 `index.html`과 함께 `art/characters/` PNG 파일을 유지한다.

## 검증

PNG를 직접 디코딩해 다섯 스프라이트의 RGBA·1024×1536 캔버스·투명 배경·장비 여백을 검증했다. 발 기준선 차이는 20px이며, 전용 카드의 얼굴과 장비도 전신 스프라이트와 대조했다.

`node --test tests/*.test.mjs`에서 이미지 파일과 부위 좌표, 영입과 교대, 전투 화면과 포즈 복구를 확인한다.

스프라이트 PNG는 생성본을 사용한다. 전용 카드 일러스트는 기존 표시 비율에 맞춰 480×200 WebP로 내보냈다.
