# 적용된 V5 SD 캐릭터

V5 원화를 참조해 built-in `image_gen`으로 제작한 투명 전신 PNG를 게임에 연결했다. 수녀는 작은 검은 베일·얇은 흰 띠·흰 어깨천·등불·둥근 방패, 여성 간수는 붉은 포니테일·제복·진압봉·사각 방패, 여성 개화 수감자는 은발·붕대·짧은 사슬을 유지한다. 세 인물 모두 앞뒤 허리천과 불투명한 안쪽 짧은 바지를 사용한다.

## 연결 방식

- `index.html`의 `partyArt`에서 파일을 배정하고 `bodyAnchors`에 SD용 부위 위치를 둔다. 세 파일은 미리 불러온다.
- 동료가 있으면 수녀·현재 동료·적이 전장에 나란히 선다. [공격·피격 키포즈](motion/README.md)는 실제 동료 이미지에도 연결된다.
- 2:3 비율을 유지해 이미지를 표시하고 발 기준선 차이는 20px(원본 높이 약 1.3%) 이내다. 화면 폭에 맞춰 세로 비율도 같이 줄인다.
- 전장 인물 위 부위 점과 공격 연결선은 숨긴다. 세부 내구도·가드는 인물별 ‘부위 상태’를 펼쳐 확인한다. 펼친 상태는 다음 행동 렌더링에도 유지한다.
- 동료 교체 시 파일이 바뀌고 사망한 동료는 전장에서 사라진다. 조우 화면에서도 같은 인물 이미지를 사용한다.
- 게임 배포·복사 시 `index.html`과 함께 `art/characters/` PNG 파일을 유지한다.

## 검증

PNG를 직접 디코딩해 RGBA·1024×1536 크기·투명 배경(완전 투명 픽셀 40% 이상)·네 모서리 알파 1 이하·머리/도구/발 안전 여백을 검증했다. 세 파일의 완전 투명 픽셀 수는 수녀 944480, 간수 878630, 개화 수감자 978935다. 기준 시트와 머리·복장·장비도 대조했다.

`node --test tests/deckbuilding.test.mjs tests/auto-battle.test.mjs tests/character-art.test.mjs tests/combat-presentation.test.mjs`의 32개 테스트와 45판 자동 진행으로 확인한다. 이미지 파일·부위 좌표, 동료 합류/교체/사망, 전장 배치 마크업·부위 패널 상태 유지·포즈 복구·경로 축약을 확인한다.

실제 브라우저의 픽셀 배치·애니메이션·모바일 터치 확인은 도구의 로컬 파일 접근 제한으로 직접 수행하지 못했다. 스크린샷으로 확인했다는 주장은 하지 않는다. 기본 PNG는 후처리하지 않았으며 게임에서 CSS로 크기·위치를 맞춘다. 포즈 PNG는 생성 시트를 기계적으로 분리·등비 축소/확대·발 위치 등록했다.
