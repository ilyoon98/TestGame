# SD · 로인클로스형 허리천 · 작은 수녀 베일 V5

사용자가 선택한 SD 비율과 Loincloth 스타일을 결합한 캐릭터 시안이다. 약 3.5등신의 비성적인 SD 표현으로, 허리에서 앞뒤로 별도 천 패널이 내려오고 옆이 트인 구조를 사용한다. 안쪽에는 불투명한 짧은 바지를 두어 독립적인 앞뒤 패널과 구분한다.

추가 피드백인 ‘수녀 모자는 좋지만 최소화’를 반영해 수녀의 최종 변형은 작은 머리 덮개·얇은 흰 띠·목덜미까지 오는 짧은 검은 베일로 정리했다. 흰 어깨천은 그대로 의상에 남기고 얼굴·머리카락·어깨 실루엣이 보이게 했다.

## 검수

- 세 인물의 앞뒤 패널이 연속된 치마와 구분되며, 옆모습과 구조도에서 안쪽 짧은 바지를 확인할 수 있다.
- 수녀의 최소화한 베일을 큰 전신·전후측면·표정·독립 장비 그림에 모두 반영했다. 등과 어깨를 덮던 큰 천은 사라졌다.
- 수녀의 흰 어깨천·목을 덮는 옷·등불·둥근 방패, 간수의 높은 깃·진압봉·사각 방패, 개화 수감자의 은발·붕대·짧은 사슬은 유지했다.
- SD 인물은 실용적인 불투명 의상과 비성적인 자세로 통일했다. 기존 V4 성인 비율의 관능적인 의상은 이번 시안에 가져오지 않았다.

이 시트를 기준으로 별도 제작한 [투명 전신 PNG 3종](../../characters/README.md)을 실제 게임의 수녀와 여성 동료에 적용했다. 시트 자체를 잘라 쓰지 않고 전장에 맞는 전신·공통 캔버스로 만들었다. 전투 전체 자동 진행 규칙은 계속 유지한다.
