# 수녀·여성 동료 — 성인 데포르메 v4

## 짧은 치마 변형

사용자 요청으로 수녀와 여성 동료 둘의 치마·코트 자락을 허벅지 중간 길이로 줄였다. 기존 성인 얼굴·체형·상반신 복장·장비와 화풍을 유지하고 정면·측면·후면에도 같은 길이를 적용했다. 수녀의 긴 베일·흰 어깨천은 유지한다.

- [수녀 — 짧은 치마](nun-concept-v4-short-skirt.png)
- [여성 동료 둘 — 짧은 치마](allies-concept-v4-short-skirt.png)
- [편집 프롬프트](PROMPTS-SHORT-SKIRT.md)

검수: 세 인물의 긴 치마·코트 꼬리가 사라지고 짧은 단과 스타킹이 보인다. 각 시트의 작은 전후측면에도 길이가 일치하며 얼굴·장비·수녀의 베일과 어깨천이 유지된다. built-in `image_gen` 편집이며 기존 긴 치마 버전은 비교용으로 보관한다.

## 기존 긴 치마 버전

사용자의 ‘수녀와 아군을 더 섹시하게’라는 피드백을 반영한 성인 비율의 비교 시안이다. 큰 머리의 SD를 직접 관능적으로 바꾸기보다, 성인으로 읽히는 얼굴·다리·허리 비율을 늘려 별도로 디자인했다. v3 SD와 최종 채택을 비교할 수 있다.

| 파일 | 내용 |
| --- | --- |
| [수녀](nun-concept-v4.png) | 긴 검은 베일·흰 머리천과 어깨천·긴 수도복을 유지. 몸에 맞춘 허리와 몸통, 한쪽 높은 옆트임·스타킹·굽 있는 부츠·자신감 있는 표정으로 성숙한 매력을 제안 |
| [여성 동료 둘](allies-concept-v4.png) | 제복의 구조와 붉은 포니테일을 살린 간수, 은발과 비대칭 수감복·붕대·사슬을 유지한 개화 수감자. 성인 체형·네크라인·스타킹·자세를 강화 |

도구: built-in `image_gen`. [프롬프트와 캐릭터 기준](PROMPTS.md) · [비주얼 기획](../../../VISUAL_DESIGN.md)

## 검수

- 수녀의 큰 실루엣은 긴 검은 베일·흰 어깨천·긴 검은 수도복이다. 앞치마·프릴 미니스커트·외부 코르셋 끈을 사용하지 않아 메이드와 구분한다.
- 수녀 시트의 앞·옆·뒤와 표정에 검은 단발·호박색 눈·성인 얼굴·몸 비율·수도복·옆트임이 유지된다.
- 여성 간수의 제복·진압봉·사각 방패와 개화 수감자의 은발·비대칭 천·붕대·짧은 사슬이 구별된다.
- 세 인물 모두 명확한 성인으로 읽히며 불투명한 옷을 입는다. 매력은 실루엣·옆트임·스타킹·표정에서 나온다.

이번에는 캐릭터 원화 2장을 추가했으며 실제 게임 원화·자동 전투 코드는 변경하지 않았다. SD 전투 캐릭터와 성인 비율의 상세 원화를 병행할지는 별도 선택 사항이다.
