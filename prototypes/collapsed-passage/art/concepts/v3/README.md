# 붕괴 통로 — SD 수녀와 전투 전체 자동 진행

## 시안의 기준과 검수

- 수녀의 큰 덩어리는 검은 베일·흰 머리천과 어깨천·긴 검은 수도복이다. v2의 코르셋·프릴 미니스커트·가터를 사용하지 않아 수녀의 정체성을 회복했다.
- 귀여움은 큰 머리·눈·표정, 작은 등불·방패·부츠에서 나온다. 몸에 덧붙이는 장식은 적게 유지한다.
- 여성 간수는 붉은 포니테일·높은 깃의 제복·진압봉·사각 방패로 구별한다. 개화한 수감자의 별도 SD 시트는 아직 제작하지 않았다.
- 사형수는 같은 인간 얼굴·긴 수감복·족쇄로 뒤편에서 접근하고, 일반 적은 전경에서 길을 막는다. 추격자는 더 긴 실루엣으로 위압감을 주었다.
- 새 게임 화면에는 매 턴 예약·실행 버튼이 없고, 자동 전투 관전과 일시정지·배속만 표시했다.

게임 화면은 원화 제안이다. 실제 프로그램에는 전투 전체 자동 진행을 구현했으며, SD 캐릭터 이미지 교체는 별도 작업이다. 원화 속 카드 비용·체력·효과는 실제 수치와 같다고 가정하지 않는다. 작은 게임 화면에 적용할 때 부위별 부상은 넓은 외부 표식과 몸의 자세로 보완해야 한다.
