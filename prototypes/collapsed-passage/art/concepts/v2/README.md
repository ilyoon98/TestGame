## 오토배틀 시안의 가정

사용자는 오토배틀 전환도 고민 중이다. 조작 범위를 아직 확정하지 않았으므로 게임 화면은 **턴마다 카드·표적을 예약하고 한 턴을 자동 실행하는 방식**을 가정했다.

1. 손패에서 행동을 골라 스태미너 한도 안에 순서를 정한다.
2. 누가 행동하고 어느 아군·적 부위를 대상으로 하는지 예약한다.
3. ‘자동 실행’으로 그 턴의 행동을 연속 재생한다.
4. 부상과 적의 행동 결과를 확인하고 다음 턴을 준비한다.

이 방향은 동료·덱 구성과 부위 선택의 판단을 유지하면서 카드마다 클릭하고 기다리는 빈도를 줄이는 제안이다. 전투 전체를 자동으로 돌리는 방향을 택하면 전투 전 덱 구성·행동 우선순위·동료 배치 쪽으로 판단을 옮겨야 한다. 이번에는 실제 전투 엔진 변경 없이 원화와 화면 제안만 제작했다.

게임 화면의 체력·카드 비용·대기열 아이콘은 설명용 예시다. 현재 게임 수치를 재현한 스크린샷이 아니다. 구현 시에는 스태미너 한도, 부상으로 사용 불가해진 예약 행동, 먼저 쓰러진 표적, 동료 사망과 다음 예약의 처리 규칙을 따로 정해야 한다.

## 검수 결과

- 여성 아군 둘은 붉은 포니테일·제복·진압봉·사각 방패와 은발·수감복·붕대·짧은 사슬로 구별된다.
- 수녀는 검은 단발·상아색 레이스 베일·촛불 봉인 문양의 둥근 방패·리본 달린 등불을 시트와 게임 화면에 유지했다.
- 게임 화면의 동료는 여성 간수 한 명이다. 일반 적은 수감복을 입은 방패 탈옥수이고, 사형수는 뒤의 철문에서 별도로 접근한다.
- 보라색 음영과 밝은 얼굴·상아색 천·촛불이 분리되어 인물과 위협을 읽을 수 있다.
- 시트의 레이스·십자 장식은 게임용 작은 스프라이트로 만들 때 단순화가 필요하다. 귀여움의 비율과 장식 밀도는 이 시안을 본 사용자 피드백으로 더 조정할 수 있다.
- v2는 컨셉 검토용이며 현재 게임의 캐릭터 원화나 전투 코드에 자동 적용하지 않았다.
