## 검수

- 수녀의 베일·수도복·등불·둥근 방패가 시트와 게임 화면에서 유지됨.
- 동료 간수의 제복·사각 방패가 일반 죄수의 수감복과 구별됨. 개화한 동료는 머리·얼굴·스카프·짧은 사슬로 추격자와 구별됨.
- 일반 적 3종은 수감복을 바탕으로 도구와 자세가 다르고, 제복 부대나 좀비 떼로 표현되지 않음.
- 사형수는 사형 집행인 장비 없이 동일한 인간 얼굴·수감복·족쇄로 기도 장면과 추격 장면에 등장함.
- 게임 화면에서는 사형수를 먼 후방 문에, 전투 상대를 출구 앞에 분리함. 동료는 간수 1명만 등장함.
- 게임 화면 초안에서 섞였던 일반 적 얼굴을 방패 탈옥수의 시트에 맞춰 보정한 결과를 최종 파일로 저장함.

## 적용 전 남은 작업

원화는 아직 게임에 교체 적용하지 않았다. 실제 UI의 글자·카드 비용·부위 타깃·추격 수치는 코드에서 렌더링해야 한다. 컨셉 화면의 작은 카드 아이콘과 숫자는 분위기 제안이다. 스프라이트로 쓸 경우 시트에서 직접 자르기보다 같은 디자인을 기준으로 포즈·크기·레이어를 통일한 별도 에셋 제작이 필요하다. 개화의 구체적인 외형과 사형수의 추격 이유는 계속 열어둔다.
