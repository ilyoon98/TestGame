# 루치아: 빈콜리의 등불 첫 구간 밸런스

첫 구간은 격리문에서 시작해 뒤틀린 벨보이를 이기고 지상 출구에 도달할 때까지다. 기본 지도는 일반 전투 두 번과 보스전 한 번으로 진행된다. 시작과 출구를 포함해 경로당 4~5방이다. 이번 조정의 기준은 고정 정책에서 탈출률 약 75%이며, 실제 플레이어 목표치는 플레이 기록을 모아 판단한다.

## 같은 45개 시드에서 규칙 비교

`classic-regression-v1`은 기존 회귀 테스트의 편성, 경로, 보상 고르기 정책을 그대로 쓴다. 시드 1~45로 각 판을 실제 전투 엔진에서 끝까지 실행했다. 시작 도망 여유 5, 벨보이 체력 27에서 이전 규칙을 각각 재현해 비교했다.

| 규칙 조합 | 탈출 |
| --- | ---: |
| 변경 전 가드·표적·보상 규칙을 재현 | 30 / 45 |
| 가드만 현재 규칙으로 전환 | 22 / 45 |
| 현재 가드·표적·보상 규칙 | 24 / 45 |
| 현재 표적·보상에서 가드만 이전 규칙으로 복원 | 32 / 45 |

가드 변경의 짝지은 차이는 두 비교에서 모두 **8판**이다. 같은 8개 시드가 예전 가드에서 탈출했다. 표적 선택만 바꾸면 이 표본의 탈출 여부는 같았고, 보상 우선순위는 2판을 구했다. 현재 규칙의 조정 전 실패 21판은 모두 승강기실에서 추격에 잡혔다.

## 적용한 조정

부위별 가드와 타격 한정 관통을 사용한다. 벨보이 전체 체력을 **27에서 23**으로 조정했다. 도망 여유 5, 머리 내구도 21, 철문 개방 1.5초의 3전투 구성이 기준이다. 비교 실험에서 시작 도망 여유 6은 33/45였고, 7과 철문 개방 1.6초는 각각 45/45였다.

| 검증 표본과 정책 | 체력 27 | 체력 23 |
| --- | ---: | ---: |
| 기존 정책, 시드 1~45 | 24 / 45 (53.3%) | 34 / 45 (75.6%) |
| 기존 정책, 독립 확인 시드 226~405 | 80 / 180 (44.4%) | 133 / 180 (73.9%) |
| 경로와 보상 칸을 따로 순환, 시드 226~405 | 79 / 180 (43.9%) | 145 / 180 (80.6%) |
| 무작위 경로·보상 및 동료 조합 순환, 기본 지도 시드 1~180 | 31 / 180 (17.2%) | 74 / 180 (41.1%) |
| 같은 정책, 생성 지도 시드 1~180 | 73 / 180 (40.6%) | 107 / 180 (59.4%) |

생성 지도 실험은 두 구간에 방을 3개씩 두고 상점·휴게소·엘리트·사건을 하나씩 넣었다. 출구까지 가면 격리문, 중간 구간 두 방, 승강기실, 출구의 총 5방을 방문한다.

환기 통로가 난도 병목으로 남는다. 조정 후 기존 45개 시드의 환기 통로는 4/15, 의무실과 정비 계단은 각각 15/15였다. 독립 확인 180개 시드에서 보상 칸과 경로를 분리해도 환기 통로는 25/60, 나머지 두 경로는 각각 60/60이었다. 무작위 선택을 섞은 정책에서는 기본 지도에서도 전체 탈출률이 41.1%였다. 약 75%의 집계는 기존 QA 정책을 기준으로 한다.

## 재현

- `node scripts/first-stage-balance.mjs --ablate --jsonl`은 가드·표적·보상 규칙 여덟 조합을 이전 수치에 고정해 판별로 기록한다. 변경 전 항목은 이전 규칙 재현이다.
- `node scripts/first-stage-balance.mjs`는 현재 게임 수치로 기존 45개 시드를 실행한다.
- `node scripts/first-stage-balance.mjs --vitality 23 --first 226 --count 180 --rotate-reward --jsonl`은 독립 확인 시드의 대체 정책을 비교한다. 실행 기록에는 시드, 경로, 선택한 보상, 최저 도망 여유, 종료 원인이 포함된다.
- `node scripts/reward-simulation.mjs --runs 180`은 동료 조합을 순환하고 지도 경로와 보상 칸을 시드 난수로 고른다. 기본 지도에서는 `--classic`을 추가한다.

단계별 계측과 다른 정책 비교는 [Mega Crit의 GDC 발표](https://www.gdcvault.com/play/1025731)와 [game-balance-design](https://www.skills.sh/haxqer/skills/game-balance-design)의 플레이어 집단 구분을 참고했다.
