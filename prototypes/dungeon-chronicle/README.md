# 판타지 모험록 — 던전과 마을의 삶

1세의 출생부터 시작하는 한국어 텍스트 시뮬레이션입니다. 종족·특성 2개·부모의 이름과 생업·사는 곳·가정 형편을 무작위로 정합니다. 유년기는 자동으로 흐르고 18세에 첫 직업이 정해집니다. 성장 후 탐험이나 일을 자유롭게 고릅니다. 사건은 위치와 나이를 붙여 한 줄씩 진행하고, 중요한 순간에는 선택 팝업이 뜹니다.

## 실행

Node.js 18 이상에서 별도 설치 없이 실행합니다.

```sh
npm start
```

`http://127.0.0.1:4173`에서 실행합니다. 포트는 `DUNGEON_PORT` 환경 변수로 바꿀 수 있습니다.

```sh
npm test
```

## 기억의 묘지

묘지에서는 이름·종족·직업으로 기록을 찾거나 ‘최근 묘비로’ 이동할 수 있습니다. 아래의 ‘기록 백업’으로 묘비 전체와 최근 생애 20개를 JSON 파일에 보관하고 ‘백업 불러오기’로 합칠 수 있습니다. 같은 ID는 기존 기록을 우선하고 진행 중인 이야기는 유지합니다. 자세한 이번 개선 내용은 [docs/improvements.md](docs/improvements.md)에 있습니다.

기억의 묘지는 별도 화면의 긴 가로 맵입니다. 밤의 숲과 돌길에서 방향키·A/D·모바일 좌우 버튼으로 여행자를 움직입니다. 묘비 앞에서 이름과 생애 요약을 보고 E키로 기록을 읽습니다. 방문 중에는 현재 이야기를 멈춥니다. 삶이 끝나면 생애 결과 창이 자동으로 뜹니다. 사망한 인물은 종족·첫 직업·마지막 생활·두 특성·나이와 생애 흔적을 조합한 픽셀 묘비로 남습니다. 어려운 성취에는 왕관·별·모루·등불·금화 장식이 추가됩니다. 기존 사망 기록도 이관하며 묘비 요약은 20개 제한 없이 별도로 보관합니다. 전체 로그는 최근 20개까지 유지합니다. 상세 조건은 `docs/memorials.md`에 있습니다.

## 던전 사건과 후속 인연

종족 전용 5종, 직업 전용 5종, 특성 사건 5종, 공통 3종과 후속 13종으로 새 던전 사건 31종에 세 번째 만남 8종을 더해 총 39종으로 늘렸습니다. 모든 특성에 전용 선택지가 있고, 과거의 구조·수리·기록·약탈은 다음 원정의 재회·보급·비밀 통로·추적으로 이어집니다. 기존 상자·만남 자리에 섞어 원정당 1~2자리를 유지하며, 같은 사건은 한 생애에 한 번만 나옵니다. [사건 연결표](docs/dungeon-events.md)에서 조건과 저장 규칙을 볼 수 있습니다. 기존 진행과 선택은 그대로 유지하고 다음 원정부터 새 사건 풀을 씁니다.

재회의 선택도 다시 갈라집니다. 광부의 보급과 지도, 정찰대의 정보와 간호, 보관함의 은화와 기록, 추적자와의 합의와 싸움이 서로 다른 세 번째 만남으로 이어집니다. [세 번째 만남 연결표](docs/dungeon-chapters.md)에 분기와 호환 규칙을 정리했습니다.

던전의 인연은 은퇴 후에도 이어집니다. 여관·길드 각 6종, 상인·장인 각 7종으로 총 26종의 재회가 있습니다. 광부의 정기 숙박, 정찰병의 순찰과 신입 교육, 약초꾼의 간호실, 고블린 상단의 보급 계약, 유족의 식탁과 탐사 기록 검증으로 연결됩니다. 과거에 해결한 분쟁은 다시 돈을 요구하지 않고, 남은 분쟁을 마을에서 해결하면 던전의 추적도 끝납니다. 기존 3~5년 생활 사건 자리를 사용하고 일반 사건과 번갈아 나옵니다. 상점에서는 광석 납품·보급·약초 위탁·상단 공동 매입으로, 공방에서는 곡괭이·경량 장비·보조 도구·짐틀 제작으로 이어집니다. 함께 읽은 지도·나눈 붕대·배운 약초·기부한 꾸러미·연구한 회로에 따라 의뢰와 보답도 달라집니다. 재회는 저장·생애 기록·묘지 요약·백업에도 남습니다. [마을 재회 연결표](docs/town-connections.md)에 조건과 효과를 정리했습니다.

인연의 대표 인물은 이제 고정된 이름을 갖습니다. 선택에 따라 아는 사이·신뢰·절친·불화로 변하고, 기존 재회 뒤의 추가 두 단계가 부탁·답례·갈등·화해로 갈라집니다. 던전에서도 관계에 따라 보답과 도움의 비용이 달라집니다. 캐릭터 창의 명부, 생애 결과와 묘지에서 이름과 관계를 볼 수 있습니다. [이름과 관계 규칙](docs/named-relationships.md)에 저장·진행 규칙을 정리했습니다.

인연마다 종족 몸체와 생업에 맞는 직업 장비를 조합한 외형을 저장합니다. 던전의 만남·동행·마을 재회·인연 명부·생애 결과·묘지 방문과 사망한 인연의 기록에 같은 모습을 사용합니다. 기존 기록도 이름을 유지한 채 외형을 보완합니다. [인연 외형 규칙](docs/npc-appearance.md)에 외형 배정과 호환 규칙을 정리했습니다.

신뢰를 쌓은 인연과 던전에서 다음 세 구간을 함께 걸을 수 있습니다. 서로 구하는 과정에서 인연이 부상하거나 사망할 수 있고, 이후 간호·재활·은퇴·추모로 이어집니다. 사망한 인물은 다시 등장하지 않으며 마을의 일상과 묘지에도 동행의 기억이 남습니다. [동행과 기억 규칙](docs/companions.md)에 확률·간격·저장 규칙을 정리했습니다.

## 플레이

- 전투력·체력·탐색력·행운·소지금·평판·피로는 가로 막대와 실제 수치로 표시합니다. 막대의 표시 기준은 전투력 50, 탐색력 30, 행운 25, 금화 500이며 게임 능력의 상한은 아닙니다. 체력은 최대 체력, 평판·피로는 100을 기준으로 합니다.
- 난이도 선택 항목은 없습니다. 적의 강함은 던전과 층수로 정하고 캐릭터의 전투력에 맞춰 자동으로 강화하지 않습니다.
- 캐릭터 창에 종족 고유 효과와 전용 사건을 표시합니다. 종족의 기본 능력·고유 효과는 무작위 특성 2개와 별개입니다.
- 출생 추첨은 종족 → 첫 특성 → 둘째 특성을 자동 공개합니다. 종족 5초, 첫 특성 6초, 전체 결과 6.5초 읽을 시간을 두며 화면에는 초 숫자와 게이지를 표시하지 않습니다. 직업은 미리 뽑지 않으며 18세에 무작위로 정해 별도 애니메이션과 효과를 6.5초 보여줍니다. 단계별 다음 버튼 없이 자동으로 이어지며 잠깐 멈추거나 전체 공개를 건너뛸 수 있습니다. 건너뛰어도 결과는 같고 동작 줄이기 환경에서는 모션만 생략합니다.
- 1세에 출생과 가족의 생업을 기록하고, 2~17세에는 가족·학교·놀이·일손 돕기·질병·간호·회복·사고를 자동 기록합니다. 부모와 가정 형편은 간호 기록과 질병의 위험에도 이어집니다. 언데드는 깨어나 가족을 만나는 출생 기록을 사용합니다. 성장 전에는 직업·장비·물약이 없고 진로 선택창도 뜨지 않습니다.
- 성장 후 여관주인·길드 직원·상인·장인으로 일하거나 던전을 탐험할 수 있습니다.
- 이끼 광산 2~4층, 속삭이는 묘지 4~6층, 별잠긴 유적 6~8층은 각각 다른 적·풍경·보스·보물을 제공합니다. 새 삶마다 층수와 층당 4~8구간을 시드로 정하며 재방문 시에는 구조를 유지합니다. 지도는 지나온 층만 공개하고 상자·만남의 유무와 위치는 원정마다 다시 정합니다. 모험을 떠나면 능력에 따른 가중 확률로 던전을 발견하며 직전 방문지는 확률이 낮아집니다. 일반 층 이동은 자동이고 언제든 나갈 수 있습니다.
- 탐험 도중 `마을로 나가기`, 생활 도중 `다른 길 고르기`로 다음 길을 고릅니다. 종족·특성·능력·자산·장비·인연은 유지합니다.
- 전투는 패배·기습으로 끝날 수 있고 붕괴는 선택창 없이 일어납니다. 깊은 던전의 적과 함정은 더 위험합니다. 보스는 연속 공격을 버틴 뒤에도 제압에 실패할 수 있으며, 남겨둔 물약은 공격 사이에 사용합니다. 위험한 상자를 열면 폭발과 저주를 감수합니다. 같은 장비와 같은 탐험에서 반복된 망자의 기억으로 전투력이 무한히 늘어나지 않습니다.
- 직업을 그만두거나 던전을 정복해도 이야기는 이어집니다. `이야기를 마무리한다`로 전체 기록을 종료합니다. 사망 시에도 종료됩니다.
- 생활 한 기록은 한 해를 뜻합니다. 큰 사건은 대략 3~5년에 한 번만 묻고 매년 일을 계속할지 묻지 않습니다. 자동 선택은 생을 마칠 때까지 이어집니다.
- 생활에서는 금화·평판·피로가 변하고, 선택에 따른 보답·저주·장비·기술이 이후 일과 탐험에 이어집니다.
- 생활의 중요 사건은 직업별 7개, 총 28개입니다. 같은 사건은 한 생애에 한 번만 나오고, 나이·평판·자산·이전 질병·전쟁에 따라 등장 가능성이 달라집니다. 일상 기록도 순서를 섞어 한 묶음 안에서 중복되지 않게 합니다. 여관 확장·공방 개선·도움 인력·검역소는 이후 수입·피로·질병 위험에 실제 영향을 줍니다.
- 종족별 노화 시작 n은 인간 60세, 엘프·언데드 68세, 드워프 65세, 고블린 54세입니다. n세부터 매년 한 번 판정하며 10년마다 연간 노환 사망 확률이 2% → 8% → 20% → 45% → 80% → 95%로 올라갑니다. 마지막 구간은 95%를 유지하고 고정 사망 나이는 없습니다. 같은 나이의 던전 진행·저장 복원으로 판정을 반복하지 않습니다. 마을에서도 돌연 사고·열병·전쟁으로 생을 마칠 수 있고 질병·전쟁은 전용 후속 기록을 사용합니다.
- 자동 결정은 시드와 태생 특성·체력·피로를 기준으로 가중치를 줍니다. 같은 선택을 다시 표시해도 예약은 바뀌지 않으며 저장 후에도 같은 결과를 복원합니다.
- 던전 로그에는 던전과 층수, 생활 로그에는 장소와 생활 개월 수를 붙입니다. 줄바꿈 없이 표시하며 긴 줄은 좌우로 스크롤합니다.
- 자동 선택은 배속과 관계없이 5초 게이지 뒤 실행됩니다. 예정된 선택을 바꾸거나 직접 선택할 수 있고, 취소하면 다시 켜기 전까지 다음 선택도 수동으로 기다립니다. 팝업을 내려둬도 같은 게이지가 기록 화면에 표시됩니다.
- 새 삶의 진로·생활·던전 선택은 기본으로 자동 진행합니다. 취소한 뒤에는 저장·복원 후에도 수동을 유지하고, 새 삶을 시작하면 자동으로 돌아갑니다. 구버전의 기본 수동 설정은 첫 업데이트 때 자동으로 전환합니다. 생활 직업은 네 가지를 비슷한 비중으로 배정하고 종족·첫 직업·특성의 선호를 약하게 반영합니다. 전직 때에는 아직 하지 않은 일을 조금 더 선호합니다.
- 새 삶은 1세에 시작합니다. 유년기와 생활 한 기록에 한 해, 던전 한 구간에 하루가 흐릅니다. 원정 준비·이동 1~2년과 귀환 회복 0~1년에도 나이가 들고 매해 노화를 판정합니다. 질병의 간호와 결과는 같은 나이에 이어집니다. 12개월은 1년(360일)입니다. 나이·가족·질병 분기·경과 시간은 저장 후에도 유지합니다. 사망 나이·장소·원인을 기록과 내보내기에 남깁니다. 종족별 수명에 도달하면 마을에서도 생을 마칩니다. 기존 성인 저장은 유지하며 화면 위의 ‘새 삶 시작’으로 출생부터 새로 시작할 수 있습니다.
- 특성은 게임에서 직접 만든 툴팁으로 설명합니다. 마우스 오버·키보드 포커스·터치를 지원하며 화면 밖으로 넘치지 않게 배치합니다.
- 선택 팝업을 내려둬도 진행은 멈춰 있습니다. 자동 선택·배속·일시정지와 브라우저 저장을 지원합니다.

## 구성

- `dist/engine.js`: 캐릭터 생성, 재현 가능한 난수, 던전 사건·전투·선택
- `dist/world.js`: 생활·탐험 전환, 세 던전, 네 생활 직업과 후속 사건
- `dist/town-connections.js`: 던전 인연의 마을 재회, 과거 선택·계약·분쟁 상태와 저장 이관
- `dist/relationships.js`: 시드로 정한 인물 이름, 관계·교류 기록, 관계별 두 단계 재회와 던전의 거래 조건
- `dist/npc-appearance.js`: 인연의 고정 종족·생업 장비 조합과 구버전 외형 복원
- `dist/companions.js`: 짧은 동행, 양방향 구조, 인연의 부상·사망과 마을의 후속 기억
- `dist/companion-graves.js`: 죽은 인연의 독립 묘비, 함께 겪은 사건과 사망 기록, 기존 저장 복원
- `dist/grave-visits.js`: 살아남은 인연의 사후 방문, 공유 사건의 회상과 추모 꽃
- `dist/cemetery-visits.js`: 묘비로 걷기·헌화·머물기·귀가 장면과 재생 상태
- `dist/app.js`: 자동 진행, 선택 팝업, 저장·복원, 최근 20개 이야기와 텍스트 내보내기
- `dist/index.html`, `style.css`, `characters.css`, `world.css`: 반응형 UI
- `dist/visuals.js`: 종족 몸체와 고정 좌표의 직업 장비·픽셀 아이콘
- `dist/assets/race-bases-simple.png`: imagegen으로 만든 단순한 종족 기본 몸체
- `dist/assets/race-bases-undead-face-v3.png`: 원본 시트를 편집한 해골 얼굴. 언데드 얼굴만 원본 몸 위에 겹칩니다. 이전 개정 몸체는 사용하지 않습니다.
- `server.mjs`: 의존성이 없는 로컬 정적 서버
- `tests/`: 던전·세계 진행과 저장, 이탈·전직, 자원·선택 결과, 픽셀 레이어 검증

260개 테스트에 기존 던전 500판·판타지 이야기 1,000판·유년기 5,000판·종족별 생활 수명 총 2,000판·자동 생활 직업 5,000명과 난이도 시뮬레이션 13,000판이 포함됩니다. 자동 생활 직업은 여관 1,287명·길드 1,168명·상인 1,290명·장인 1,255명으로 고르게 분포합니다. 유년기 사망은 11.92%이며 마을 생활 중앙 사망 나이는 종족별 64~72세입니다. 노화 구간 경계·같은 나이 중복 판정 방지·시드와 저장 복원도 검증합니다. `node tests/balance-simulation.mjs --report`는 유년기 사망을 제외한 성인 첫 탐험을 비교합니다. 수명·사건 규칙은 `docs/life-variety.md`, 던전 기준은 `docs/dungeon-balance.md`에 있습니다. 배포용 파일은 `dist/`에 있으며 기존 저장도 이어서 사용할 수 있습니다.

종족 몸체와 모든 장비는 같은 32×48 캔버스를 씁니다. 배낭은 뒤에, 옷·모자·무기는 앞에 고정 좌표로 얹습니다. 자세한 내용은 `docs/pixel-layers.md`, 생성 프롬프트는 `docs/art-prompts.md`, 세계 진행 규칙은 `docs/fantasy-life-plan.md`에 있습니다.
