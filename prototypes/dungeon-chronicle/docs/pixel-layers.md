# 공통 좌표로 조합하는 픽셀 캐릭터

모든 종족·직업은 같은 **32 × 48 논리 픽셀 캔버스**를 사용한다. 화면에서는 캔버스 전체를 확대하고 `pixelated` / `crispEdges`로 그린다.

## 레이어 순서

1. 뒤쪽 장비: 배낭, 보따리, 망토 등
2. 종족 기본 몸체
3. 언데드 얼굴: 원본 몸 위에 해골 얼굴 부분만 겹친다.
4. 앞쪽 장비: 옷, 모자, 무기, 어깨끈 등

종족과 직업을 합친 완성 그림을 25장 따로 만들지 않는다. 몸체 5개와 직업별 투명 장비 레이어를 조합한다. 직업 장비는 종족과 관계없이 같은 좌표를 사용한다.

## 공통 기준점

| 기준 | 좌표 |
|---|---|
| 몸체 중심 | x = 16 |
| 머리 위 기준 | y = 12 |
| 발바닥 기준 | y = 44 |
| 모자·투구 | 머리 위 기준 주위 |
| 상의·예복 | x = 10~22, y = 26~42 |
| 짐꾼 배낭 | x = 22~31, y = 24~41, 몸체 뒤 레이어 |
| 손에 든 도구·무기 | x = 25~31, y = 20~43 |

이미지 생성으로 생긴 기본 몸체의 여백 차이는 `baseTransform()`에서 공통 중심·머리·발 기준에 맞춘다. 이 보정은 몸체에만 적용하고, 직업 장비 좌표를 종족별로 이동시키지 않는다. 새로운 몸체를 추가할 때는 기존 기준에 맞춰 그리거나 그 몸체의 범위만 등록한다.

새 직업을 추가할 때는 같은 캔버스에 배낭 또는 모자·옷·무기만 투명하게 그린다. 배낭처럼 앞뒤를 가로지르는 장비는 가방 본체를 뒤에, 어깨끈을 앞에 나눠 배치한다.

종족·직업·특성 아이콘은 16 × 16의 별도 픽셀 SVG이며 본문 이름 앞에 배치한다. 나중에 생활 직업이 추가되면 여관주인의 앞치마, 상인의 보따리, 장인의 작업복도 같은 좌표와 레이어 구조로 추가한다.

## 언데드 얼굴 변경 — v10

모든 종족의 몸은 원본 `race-bases-simple.png`를 사용한다. 언데드에도 원본의 둥근 몸·옷·팔·다리·장비 위치를 유지한다. 이전의 가느다란 별도 몸체와 추가 뼈 팔 레이어는 사용하지 않는다.

편집본 `race-bases-undead-face-v3.png`는 같은 1254×1254 투명 시트다. 아래 중앙 언데드 프레임의 얼굴에 눈구멍·코·이빨을 추가했다. 이 프레임만 원본과 같은 변환으로 겹치며, `sprite-face`의 아래 47%를 잘라 논리 y25.44 아래의 몸은 원본을 그대로 노출한다. 장비는 얼굴보다 앞에 그려진다. 다른 종족은 편집본을 사용하지 않는다.

모든 종족의 프레임은 418×627이다. 언데드의 원본 범위는 `(107,139)~(310,516)`이며 `baseTransform()`에서 기존 중심·머리·발 기준에 정렬한다. 직업별 좌표를 수정하지 않는다.
