# 던전에서 마을로 이어지는 인연

던전 선택의 결과를 실제로 겪고 살아남으면 인연을 기억한다. 사건을 보기만 하거나 지나치면 생성하지 않는다. 중간 귀환·정복·은퇴·전직과 관계없이 유지한다.

| 인연 | 여관에서의 재회 | 길드에서의 재회 |
| --- | --- | --- |
| 광부 | 정기 숙소: 금화 10, 이후 여관 수입 +2 / 식사 | 안전 절차: 금화 10, 이후 길드 피로 증가 -2 / 지도 공유 |
| 정찰병 | 공동 야간 순찰: 이후 여관 피로 증가 -2 / 경험담 | 신입 교육: 금화 8, 이후 길드 피로 증가 -2 / 매뉴얼 |
| 약초꾼 | 간호실: 금화 12, 이후 열병 악화 위험 ×0.8 / 약초 공부 | 치료망: 금화 12, 이후 열병 악화 위험 ×0.8 / 안내 업무 |
| 고블린 상단 | 정기 숙박: 금화 8, 이후 여관 수입 +2 / 길 소식 | 보급 계약: 이후 길드 수입 +1 / 공개 의뢰 |
| 유족 | 함께 기억하는 식탁 / 편지 | — |
| 탐사 기록 관계자 | — | 기록 검증 / 사적 거래 |
| 보물의 소유권 분쟁 | 남은 분쟁 중재 / 경비에게 맡기기 | 남은 분쟁 공개·합의 / 담당 이관 |

각 사건에는 무료로 지나가는 선택도 있다. 이미 합의한 분쟁은 평범한 손님·의뢰로 바뀌며 중복 변제를 요구하지 않는다. 옛 물약으로 구조한 고블린은 상단에서 일하게 된 인물로 재회하며, 경험하지 않은 벽 표식을 기억한다고 쓰지 않는다.

| 인연 | 상점에서의 거래 | 공방에서의 의뢰 |
| --- | --- | --- |
| 광부 | 광석·보급 정기 거래: 금화 12, 이후 수입 +2 / 일회 중개 | 규격 도구 정기 제작: 금화 12, 이후 수입 +2 / 수리 |
| 정찰병 | 보급 표준화: 금화 8, 이후 피로 증가 -2 / 소량 주문 | 경량 장비 틀: 금화 8, 이후 피로 증가 -2 / 원정 장비 수리 |
| 약초꾼 | 약초 위탁 선반: 금화 10, 이후 수입 +1 / 예비 물약 구매 | 보관함·보조 도구: 금화 10, 이후 수입 +1 / 채집 도구 시험 |
| 고블린 상단 | 공동 매입: 금화 14, 이후 수입 +2 / 이번 짐 거래 | 짐틀·잠금쇠 정기 제작: 금화 12, 이후 수입 +2 / 짐틀 보강 |
| 유족 | 물품의 주인 확인 / 동의를 받은 위탁 판매 | 이름을 새긴 기념패 / 맡긴 물건 수선 |
| 탐사 기록 관계자 | 유물의 출처 감정 목록: 금화 8, 이후 수입 +1 / 공동 감정 | 작동 모형: 금화 10, 전투력 +1·탐색력 +1 / 복원 도면 |
| 보물의 소유권 분쟁 | 남은 값 중재 / 매입 보류 | 남은 값 중재 / 수리 보류 |

### 과거 선택에 따른 다른 의뢰

- 광부에게 보급 대신 지도를 받았다면 경로별 납품·안전 도구 의뢰로 바뀐다. 정기 계약에 탐색력 +1이 추가된다.
- 정찰대와 통로 정보 대신 붕대와 식량을 나눴다면 구호 물자·들것 제작을 제안받는다. 해당 계약의 평판은 +3 대신 +6이다.
- 약초꾼에게 치료 대신 구별법을 배웠다면 같은 금화 6에 물약 2병을 마련하거나, 공방의 도구 시험에서 탐색력 +2를 얻는다.
- 가족의 꾸러미를 신입들에게 나눴다면 물품 반환·기념패 대신 신입의 보급품·장비 지원으로 이어진다.
- 마력 회로를 연구했다면 회로 감정·모형 의뢰에서 탐색력을 1 더 얻는다.
- 상점·공방에서도 미해결 분쟁을 금화 12로 중재하면 남은 던전 추적이 끝난다. 이미 해결한 상대는 금화 +14·평판 +3의 정식 거래나 수리를 의뢰한다. 기록이 불분명한 옛 분쟁도 재변제를 요구하지 않는다.

전용 분기를 보았다고 다른 재회 슬롯을 추가로 소비하지 않는다. 같은 사건의 내용이 과거 선택에 따라 바뀌며, 당시 공개된 내용은 저장 후에도 고정된다.

## 진행과 효과

- 여관 6종, 길드 6종, 상인 7종, 장인 7종으로 총 26종이다. 직업과 실제 인연이 모두 맞아야 등장한다.
- 기존 3~5년 간격의 큰 생활 사건 자리를 사용한다. 재회 다음 자리는 일반 생활 사건을 우선한다.
- 같은 재회는 한 생애에 한 번이다. 직업을 바꾸면 그 직업의 다른 재회를 볼 수 있다.
- 시드·특성·현재 상태를 사용하는 기존 자동 선택과 5초 게이지를 그대로 사용한다.
- 계약은 선택 결과가 기록될 때 성립한다. 비용은 한 번만 내며, 결과 전에 사망하면 계약과 추억을 얻지 못한다.
- 수입·피로 효과는 해당 직업에서만 적용된다. 간호 효과는 열병 위험을 줄이며 노화·돌연사 판정을 막지 않는다.
- 마을 중재는 아직 남은 소유권 추적만 취소한다. 다른 던전 약속과 과거 기록은 유지한다.
- 기존 희귀 성취 조건을 계약만으로 달성시키지 않는다.

## 저장과 옛 기록

`world.bonds`에 인연의 출처·선택·분쟁 상태, 본 재회, 마지막 재회 여부와 최근 추억 4개를 보관한다. 옛 저장은 완료 효과·예약된 후속 사건·고블린 구조 기록으로 이관한다. 사건을 본 기록만으로 인연을 만들지 않는다. 과거 선택이 불분명한 분쟁은 재변제를 요구하지 않는 중립 재회를 사용한다.

재회의 결과는 전체 로그·텍스트 내보내기에 남고, 최근 추억은 묘비 요약과 기록 백업에도 포함된다. 전체 로그가 오래되어 사라져도 묘지에서 마지막 재회를 읽을 수 있다.

`tests/town-connections.test.mjs`는 실제 귀환·취업 흐름, 26종 선택 결과와 과거 선택 분기, 비용·계약·피로·질병 효과, 분쟁 상태, 반복 방지, 시드 복원, 옛 저장 이관과 묘지 백업을 검증한다.

이 연결에 고정된 이름과 관계 변화, 두 단계의 추가 재회를 더했다. 기존 26종은 그대로 유지하며, 자세한 내용은 [이름과 관계 규칙](named-relationships.md)에 있다.
