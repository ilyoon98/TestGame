# 묘비를 찾아오는 장면

- 주인공의 묘비에 다가가면 저장된 `remembrance.visits`를 순서대로 재생한다. 방문자가 왼쪽 길에서 걸어와 묘비 곁에 서고, 꽃을 내려놓거나 고개를 숙인 뒤 약 5초 머물고 돌아간다. 방문자 이름·직업과 추모 문장이 같은 방문 기록을 가리킨다.
- 기존 캐릭터와 직업 장비 레이어를 사용한다. 요양처에서 보낸 편지와 꽃은 본인 대신 전달자가 가져오며 방문자 표기도 이를 구분한다. 꽃을 남기지 않은 불화·회상 장면에서는 헌화를 만들지 않는다.
- 표현 상태는 `arriving → offering → remembering → leaving → gap → complete`이다. 한 번에 한 명만 움직이며 꽃은 내려놓는 순간에 나타난다. 연출 중에는 기존 꽃 그림을 가리고 임시 꽃을 표시하고, 장면이 끝나면 저장된 묘비 그림으로 돌아간다.
- 장면은 표시 전용이다. 생애의 시드·시간·자원·사건·방문 기록과 백업은 바뀌지 않는다. ‘장면 다시 보기’로 재생해도 꽃이나 방문 기록을 추가하지 않는다. 같은 묘비에서 프레임마다 장면을 새로 만들지 않으며, 다른 묘비로 이동하면 숨기고 그 진행 위치를 보관한다.
- 기록 팝업·숨긴 탭·화면 밖 방문 장면은 정지한다. 돌아왔을 때 지난 시간을 한꺼번에 적용하지 않는다. 묘지에서 나가면 방문자와 임시 꽃을 정리한다.
- 움직임 줄이기 설정에서는 수평 걷기와 몸 흔들기를 생략하고 묘비 옆의 조용한 헌화·머무르기로 표시한다. 모바일에서는 같은 묘비 좌표에 맞춰 발 위치와 이름표 크기를 조정한다.
