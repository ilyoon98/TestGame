# 이름을 기억하는 인연

광부·정찰병·약초꾼·고블린 상단·유족·조사 관계자·표식 분쟁 당사자의 대표 인물에게 이름을 붙인다. 이름은 생애 안에서 고정되며 던전·여관·길드·상점·공방에서 같은 인물로 이어진다. 주 시뮬레이션과 별도로 저장한 시드로 정하므로 이름이나 명부를 읽어도 난수와 자동 선택은 바뀌지 않는다.

## 만남과 관계

- 관계는 -6~+6. -4 이하는 깊은 불화, -2 이하는 불화, +2 이상은 신뢰, +4 이상은 절친이다. 그 사이는 아는 사이다.
- 첫 대화를 보거나 이름을 표시하는 것만으로 호감이나 만남 횟수를 얻지 않는다. 살아서 선택 결과를 기록할 때 반영한다.
- 구조·협력은 보통 +1, 소유권 합의는 +2, 도주·적대 행위는 -2로 반영한다. 기존 인연의 부탁을 지나치면 -1, 공방·상점 등의 첫 재회에서 자신의 일에 집중하면 0이다.
- 마을의 관계 재회에서는 도움 +2, 공정한 몫 0, 급한 사정 이용 -4, 화해 +3처럼 선택의 의도를 반영한다. 횟수만 쌓인다고 친해지지 않는다.
- 벽의 표식이나 마력 회로를 조사한 일은 사람을 만난 것으로 세지 않는다. 이런 단서에서 이어진 인물은 실제 마을 재회 때부터 교류를 기록한다. 가족의 편지와 꾸러미는 기록된 교류로 센다.
- 이미 만난 인물은 캐릭터 창의 ‘맺은 인연’에서 이름·역할·관계·횟수를 본다. 직접 만든 툴팁에는 마지막 선택과 관계 수치가 나온다.

## 관계로 달라지는 다음 사건

기존 직업별 재회 26종 뒤에 인물별 추가 재회 두 단계를 둔다. 두 번 이상 교류한 인물이 대상이며, 관계 점수에 따라 신뢰의 부탁·조심스러운 제안·불만 정리로 갈라진다. 이미 불화가 생겼다면 먼저 갈등 사건이 나온다. 첫 만남에서 광부의 장비를 뜯어 간 경우도 분쟁으로 기억하며, 도운 적이 없다면 감사의 납품·제작 계약을 만들지 않는다. 첫 추가 재회에서 친분을 이용하면 다음은 갈등이나 조심스러운 약속이 되고, 도움을 이어 갔다면 답례가 온다. 갈등에서는 손해를 나눠 맡거나, 조건을 정하거나, 책임을 돌릴 수 있다. 직업별로 숙식·의뢰 연결·물자 마련·도구 제작의 내용과 비용이 다르다.

추가 재회도 기존 3~5년 생활 사건 자리를 쓰고 일반 사건과 번갈아 나온다. 같은 인물의 마을 재회에는 최소 3년을 두며, 두 단계는 직업을 바꿔도 공동으로 센다. 미해결 소유권 분쟁은 기존 중재 사건을 통해 먼저 정리해야 한다. 비용이 없어도 무료 대안이 있다.

던전의 광부·정찰대·약초꾼·상단·가족·정식 거래 후속 사건도 관계를 반영한다. 신뢰 +3 이상이면 첫 도움 선택에 금화·체력 +4 또는 평판 +2를 더한다. 불화 -2 이하라면 도움을 받기 전에 추가 금화 6과 조건을 확인한다. 다른 무료 선택지는 유지한다. 던전 사건 자리나 선택 팝업 수는 추가하지 않는다.

## 저장과 결과

`world.bonds.socialVersion`, `nameSeed`, `people`에 이름·점수·횟수·추가 재회 단계·마지막 마을 만남·마지막 선택·반영한 결과 키를 저장한다. 공개된 선택의 관계와 조건은 예약 당시 값으로 고정한다. 저장을 복원하거나 자동 예약을 다시 읽어도 비용과 보답이 바뀌지 않는다. 치명상 뒤 아직 기록되지 않은 결과는 관계·약속·추억을 주지 않는다.

옛 저장은 근거가 있는 인연만 이름을 붙여 아는 사이(점수 0, 확인된 과거 교류 1회)로 이관한다. 과거 로그·나이·선택을 고쳐 쓰거나 임의로 우정과 다툼을 만들어 내지 않는다. 이미 공개된 옛 선택도 계속 고를 수 있다.

사망 결과·묘비 요약·생애 텍스트·기록 백업에 이름과 마지막 관계·횟수를 보관한다. 최근 전체 로그가 사라져도 묘지에는 인연이 남는다. 친분만으로 희귀 묘비 업적을 얻지는 않는다.

`tests/relationships.test.mjs`는 이름 결정성, 실제 만남, 관계별 후속 분기, 화해, 7개 인연×4개 직업×관계·단계별 선택 결과, 사건 간격, 비용·저장·자동 예약, 중복·사망 방지, 던전 거래 조건, 옛 저장과 묘지 백업을 검증한다.
