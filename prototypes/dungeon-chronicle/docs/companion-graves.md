# 인연의 묘비

- 실제로 만난 인물의 사망 결과가 기록되는 즉시 기존 가로 묘지에 독립 묘비를 남긴다. 주인공의 사망이나 귀환을 기다리지 않는다. 부상·요양·은퇴는 사망으로 취급하지 않는다.
- 생애 ID와 인연 그룹으로 묘비 ID를 만든다. 저장·복원·백업을 반복해도 중복되지 않으며, 서로 다른 생애의 동명이인은 따로 보존한다.
- 묘비 앞에 다가가면 이름, 직업, 주인공과의 관계, 함께 겪은 일과 사망 장소·원인이 표시된다. E 또는 ‘함께한 기록 읽기’로 시간순 상세 기록을 연다. 사망 당시 나이는 주인공의 나이임을 명시한다. 인연 본인의 나이·종족은 알 수 없으므로 만들지 않는다.
- 실제 출력된 이름 있는 사건 결과를 최대 16개 별도 보관한다. 선택창과 예약 중인 결과는 기록하지 않는다. 이후 마을에서 추모한 일도 같은 묘비에 이어진다. 상세 생애 로그가 최근 20개 밖으로 밀려나도 묘비의 공유 기록은 유지한다.
- 중앙에는 직업 문양, 옆에는 작은 추모 꽃을 새긴다. 주인공의 희귀 업적을 인연에게 복사하지 않는다. 검색은 인연의 이름·직업·주인공 이름을 지원한다.
- 기존 세션·완료 생애·압축 묘비에 남아 있는 사망 정보로도 인연 묘비를 복구한다. 과거 상세 사건이 없으면 남아 있는 부상·사망·재회 기록만 사용하며, 알 수 없는 사건 시기는 ‘시기 기록 없음’으로 표시한다.
- JSON 백업과 텍스트 저장에 인연의 묘비·공유 사건·사망 원인을 포함한다. 백업을 합칠 때 기존 묘비가 같은 ID의 외부 기록보다 우선한다.
