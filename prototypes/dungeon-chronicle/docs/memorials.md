# 생애 결과와 기억의 묘지

묘지는 `#cemetery` 경로의 독립 화면이다. 밤의 숲·문·등불·돌길을 배경으로 묘비가 좌우로 이어진다. 드래그, 터치, 방향키, 마우스 휠, 이동 버튼과 위치 막대로 둘러본다. 묘지에 머무는 동안 현재 인물의 시간과 자동 선택을 멈추고, 돌아오면 방문 전 진행 상태로 이어간다. 오래된 사망부터 자리를 정하고 이후의 사망은 길 끝에 추가한다. 희귀 묘비를 강조해도 위치는 바뀌지 않는다.

삶이 끝나면 결과 창을 한 번 자동 표시한다. 닫은 뒤 기록 하단에서 다시 열 수 있다. 사망한 인물은 기억의 묘지에 남고, 생존한 채 이야기를 마무리한 인물은 별도 결과 목록에 남는다.

묘비의 돌 색과 윤곽은 종족, 중앙 문양은 마지막 생활 직업(없으면 첫 직업), 그 아래 문양은 첫 직업, 아래 두 표식은 태생 특성으로 정한다. 어린 삶에는 꽃이 남고 75세 이후에는 균열이 생긴다. 생애 ID·나이·특성·직업·수치로 돌 높이와 작은 흔적을 정하므로 다시 열거나 저장을 복원해도 같은 모양이다. 게임의 사건 난수는 소비하지 않는다.

| 특별 장식 | 성취 조건 |
|---|---|
| 왕관 — 세 미궁의 정복자 | 세 던전 모두 정복 |
| 별 — 별을 깨운 자 | 별잠긴 유적 정복 + 별의 심장 소지 |
| 모루 — 미궁의 명장 | 장인 경험 + 거수의 광석 활용 + 새 용광로 + 평판 80 이상 |
| 등불 — 마을의 등불 | 고블린 구조 후 방문 인연 + 검역소 조직 + 평판 90 이상 |
| 금화 — 황금 거래의 전설 | 상인 경험 + 물약 공급 신뢰 + 생전 최종 소지금 2,000 G 이상 |

한 생애가 여러 성취를 달성하면 모두 결과에 표시한다. 꼭대기 장식은 표의 위쪽 조건을 우선한다. 직업·깊은 층 도달만으로 정복 성취를 부여하지 않는다. 조건은 묘지 안에서 확인할 수 있다.

기존 브라우저의 최근 전체 기록에서 사망 기록을 추출해 이관한다. 이미 삭제되었거나 다른 브라우저에만 있는 기록은 복구하거나 만들어내지 않는다. 묘비는 `dungeon-chronicle.memorials.v1`에 로그 없이 작은 요약으로 별도 저장하며 20개 제한을 두지 않는다. 전체 로그는 기존처럼 최근 20개를 보관한다. 새 삶은 이전 삶의 능력이나 업적을 이어받지 않는다. 저장은 브라우저 로컬이며 기기 간 공유 기능은 없다.

결과 창에는 사망 나이·장소·원인, 첫 직업, 마지막 생활, 두 특성, 최고 탐험 층, 원정·처치 수, 최종 금화·평판·생활 기간·남긴 자산과 성취를 표시한다. 과거 묘비를 눌러 확인하거나 그 인물의 기록을 파일로 저장해도 현재 진행 중인 인물은 바뀌지 않는다.


## 묘지를 걷는 여행자

묘지는 현재 삶과 분리된 짐꾼 모습의 여행자로 둘러본다. 방향키·A/D를 누르고 있거나 모바일 좌우 버튼을 누르고 있으면 걷는다. 묘비를 누르면 그 앞으로 걸어가며, 바닥을 누르면 해당 지점으로 간다. 화면은 움직이는 여행자를 따라간다. 가까운 묘비 하나의 이름·나이·생활과 실제 저장 내용을 바탕으로 한 생애 요약을 자동 표시한다. E키 또는 읽기 버튼으로 기존 전체 결과·로그를 연다. 멀어지면 요약이 사라진다. 포커스가 사라지거나 기록을 열면 걷기를 멈춘다. 이동은 게임 시간·난수·자원·묘비 저장에 영향을 주지 않는다.

결과의 ‘이 묘비에 새겨진 것’은 종족·중앙 문양·첫 직업·두 특성·나이 흔적·대표 업적을 아이콘으로 표시한다. 비석의 직업·특성·장식과 같은 SVG 문양을 사용하며, 직접 만든 툴팁을 마우스·키보드 포커스·터치로 열어 뜻을 확인할 수 있다.

표식 설명의 제목 글자는 표시하지 않는다. 기본으로 접힌 설명 아이콘 하나만 두고, 클릭 또는 키보드로 펼치면 설명문과 표식 풀이를 보여준다. 다시 누르면 접힌다.
# v21 기록 찾기와 백업

묘지의 검색은 이름·종족·마지막 직업을 검색하며 결과를 누르면 그 묘비 앞에 여행자가 서게 됩니다. 최근 묘비 버튼은 가장 최근 사망 기록으로 이동합니다. 가로 맵에서 원래 묘비 위치는 바꾸지 않습니다.

기록 백업은 묘비 전체와 최근 생애 20개를 JSON으로 내보냅니다. 가져오기는 5MB 한도와 구조·버전을 확인하고 합칩니다. ID 중복은 기존 기록을 우선하며 현재 삶의 진행은 바꾸지 않습니다. 저장 공간 부족은 화면에 알리고 이전 저장 값으로 되돌립니다.
