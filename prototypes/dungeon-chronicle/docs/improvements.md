# 이번 개선 — v21

완료한 항목:

1. **시드로 정한 던전 구조**: 광산 2~4층, 묘지 4~6층, 유적 6~8층, 층당 4~8구간. 캐릭터와 던전 ID로 별도 난수 흐름을 만들어 사건 RNG와 분리한다. 같은 생애의 재방문 구조는 저장해 유지한다. 기존 저장에 구조가 없으면 과거의 3·5·7층, 6구간으로 이관한다.
2. **탐험의 변화**: 상자 70%, 고블린 만남 50% 확률로 원정마다 위치를 정하며 충돌하면 겹치지 않는다. 풍경은 섞은 묶음에서 꺼내며 묶음 경계의 연속 중복도 막는다. 방문한 층만 지도에 표시하고 정확한 끝과 남은 구간 수는 숨긴다.
3. **원정의 시간**: 준비·이동에 1~2년, 귀환 후 회복에 0~1년. 각 해에 한 줄씩 남기고 노화 판정을 매년 한 번 수행한다. 준비 중 사망 장소는 던전이 아니라 원정 준비 장소로 기록한다. 탐험 구간은 하루를 유지한다.
4. **시청 중단 시 보호**: 문서가 비활성화되거나 진행 설명·생애 결과·묘지를 보는 동안 자동 진행을 중단한다. 선택 게이지의 남은 시간은 보존하며 수동 일시정지·자동 선택 취소 설정은 유지한다. 캐릭터 공개 감상 시간도 다른 탭에서 소비되지 않는다.
5. **묘비 찾기**: 이름·종족·마지막 직업을 함께 검색한다. 검색 결과와 최근 묘비 버튼으로 해당 묘비 앞까지 이동한다. 묘비의 실제 좌표는 변경하지 않는다.
6. **기록 백업과 합치기**: 묘비 전체와 최근 생애 20개를 JSON으로 내려받는다. 5MB 이하 파일의 버전과 구조를 검증한 뒤 합친다. 중복 ID는 기존 기록을 우선하고 현재 진행 중인 삶은 바꾸지 않는다. 저장 공간 부족 시 이전 값을 되돌리고 메시지를 표시한다.

검증: `node --test`의 116개 테스트. 기존 밸런스 시뮬레이션 13,000판에서 첫 원정 광산 사망 12.25%, 묘지 40.4%, 유적 83.55%, 준비된 유적 사망 29.9%. 이 수치는 보스를 향해 계속 전진하는 정책이며 일반 자동 결정과 같지 않다. 1,000개 출생 시드의 전체 생애가 모두 사망으로 종료한다. 브라우저에서는 묘비 검색·이동, 백업 다운로드와 중복 없는 복원을 확인한다.
