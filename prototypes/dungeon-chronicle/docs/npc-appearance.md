# 인연의 고정 외형

인연은 `appearance: { version: 1, race, job }`을 갖습니다. 이름·관계와 함께 저장하며 던전 만남, 동행과 마을 재회 선택창, 명부, 생애 결과, 독립 묘비 기록, 추모 방문에 같은 외형을 사용합니다. 주인공의 종족·현재 직업을 빌려 쓰지 않습니다.

## 배정

인간·엘프·드워프·고블린·언데드의 기존 32×48 몸체에 직업 장비 레이어를 얹습니다. 광부는 짐꾼 장비, 정찰병은 도적 장비, 약초꾼은 성직자 장비, 상단과 채권자는 상인 장비, 유족은 여관 장비, 기록원은 길드 장비를 사용합니다. 직업별로 종족 후보와 가중치가 다릅니다. 기존 이야기에서 고블린으로 등장하는 상단 인연은 고블린을 유지합니다.

첫 배정은 생애 ID·인연 그룹·이름을 해시한 값으로 정하며 게임의 난수를 소비하지 않습니다. 저장된 유효 외형을 우선합니다. 같은 인연을 반복해서 만나거나 주인공이 전직하고 저장을 복원해도 바뀌지 않습니다. 현재 난수 상태 `s.seed`는 외형 생성에 사용하지 않습니다.

## 호환과 기록

- 구버전 인연과 진행 중인 선택에 외형이 없으면 같은 규칙으로 보완합니다. 이름·관계·만남 수·예약된 선택과 사건 결과는 유지합니다.
- 생애 요약, 추모 방문, 사망한 인연의 묘비에도 외형을 복사합니다. 전체 로그가 사라진 오래된 묘비에서도 같은 모습을 복원합니다.
- 기존 추모 문구·방문 날짜·헌화 기록은 바꾸지 않습니다. 백업 불러오기는 누락 외형을 보완하고 서로 모순된 외형 복사본은 거부합니다.
- 요양 중인 인연이 편지와 꽃을 보내면 인간 짐꾼인 별도 전달자가 방문합니다. 원래 인연의 외형이나 부상 상태는 바꾸지 않습니다.
- 이미 사망한 상단 인연 대신 등장하는 일반 고블린 모험가는 익명 인물로 표시합니다.

## 검증

`tests/npc-appearance.test.mjs`의 12개 테스트로 5종족 배정, 직업 장비, 난수 보존, 던전에서 추모까지 외형 일치, 구버전 저장 복원, 요약 기록과 백업 왕복, 잘못된 외형 거부, 전달자 구분을 확인합니다. 전체 260개 테스트가 통과합니다.
