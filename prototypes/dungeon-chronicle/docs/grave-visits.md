# 살아남은 인연의 추모

- 주인공이 사망한 뒤 이어지는 짧은 후일담이다. 생존한 이름 있는 인연만 방문하며, 먼저 죽은 인연을 되살리지 않는다. 직업을 그만두거나 스스로 이야기를 마친 생존 인물에게는 장례를 만들지 않는다.
- 신뢰 이상인 인연은 꽃을 놓고 간다. 절친은 한 해 뒤 다시 찾아온다. 아는 사이는 꽃이나 짧은 회상을 남기며, 불화가 남은 인연은 화해를 강요하지 않고 조용히 인사를 남긴다. 요양 중인 인연은 요양처에서 꽃과 편지를 보내며, 부상을 자동으로 회복시키지 않는다. 모험에서 은퇴한 인연도 방문할 수 있다.
- 실제 출력된 이름 있는 동행·구조·거래·재회 결과에서 기억을 고른다. 구조 기록은 우선한다. 선택창이나 아직 실행되지 않은 결과는 사용하지 않는다. 상세 로그를 잃은 구버전 묘비에는 남은 재회·동행 횟수만 반영하고 구체적인 사건이나 장소를 만들지 않는다.
- 별도 난수 호출 없이 생애 ID와 인물 정보를 해시한다. 본편의 난수·자원·시간·인연 상태를 바꾸지 않는다. 본편의 마지막 로그와 선택을 추가하지 않으며, 사망 시점 뒤의 후일담임을 일수와 기일로 구분한다.
- 묘비의 `remembrance.version=1`에 시간순 방문 기록을 최대 14개 보존한다. 한 번 저장한 후일담은 새로고침·다른 생애·로그 보관 한도·백업으로 달라지거나 증식하지 않는다. 기존 묘비에 후일담이 없으면 남은 기록으로 복구한다.
- 묘비 앞에는 전달된 꽃을 표시하고, 가까이 다가가면 방문자와 공유 기억을 읽을 수 있다. 결과 창과 생애 기록에 모든 추모를 담는다. JSON 백업은 방문자의 생존 여부·이름·관계·부상 상태와 중복 ID를 검사한다.
