# 백야선 연출

백야선은 해안 도시의 야간 사건에 여덟 현장팀을 보내는 철도 원정이다. 대원들의 콘셉트는 교전, 추적, 지원, 정리 등 사건을 처리하는 역할에서 출발한다. 플레이어는 열차로 대원을 보내고, 영입과 동기화로 다음 구간의 편성을 키운다. 현재 보드의 정거장과 적은 북단 철도 원정의 지명과 순찰기·전환기를 사용한다.

`concept-derived` 태그는 항만 반사띠, 접이식 현장 장비, 사람 얼굴 위로 읽히는 수인 실루엣이다.

| --- | --- |
| 남색 `#162638` | 관제 화면과 전투 배경 |
| 청록 `#90dade` | 아군 토큰과 목적지 고리 |

| 시점 | 화면 반응 |
| --- | --- |
| 출발 편성 | 코스트 한도 안에서 뽑힌 네 명을 전투력 순서로 한 장씩 공개한다. 카드가 뒤집힐 때마다 이름, 코스트, 누적 합계를 보여 준다. 마지막 카드가 열리면 황동색으로 바뀐 게이지를 잠깐 유지하고 주사위를 굴린다. 일시정지와 배속은 추첨에도 적용한다. |
| 주사위 굴림 | 철도 위에 주사위가 크게 나타나 튀어 오르고 면이 바뀐다. 눈을 공개하면 주사위가 줄어들며 기관차를 따라가고 정차할 때 사라진다. |
| 보드 이동 | 기관차가 한 칸씩 미끄러진다. 교차한 칼은 전투, 상자는 보급, 사람 옆 플러스 표식은 영입이다. 보급과 영입에서는 체력 회복량이나 합류한 대원의 이름을 보여 준 뒤 출발한다. |
| 합 접근 | 한 전장 선 위에 두 합의 위치를 배치하고 토큰들을 동시에 움직인다. 출전할 차례를 기다리는 대원은 전장 뒤에 줄을 선다. |
| 합 판정 | 금색 마름모 코인은 앞면, 갈색 가로 홈 코인은 뒷면, 깨진 코인은 소실을 뜻한다. 코인이 공개될 때 머리 위에 현재 합 위력과 증가치를 띄운다. 합이 부딪히면 전장이 짧게 흔들린다. 이긴 토큰은 상대 쪽 위로, 진 토큰은 뒤쪽 아래로 움직인다. 위력 격차가 클수록 섬광과 반동이 강해진다. 점수와 방향 표식은 1배속에서 1.05초간 유지한다. |
| 재접근 | 다음 합이 남아 있으면 두 토큰이 빠르게 뒤로 물러났다가 감속해서 멈추고, 코인을 다시 던질 때 중앙으로 붙는다. 판정 때 중앙에서 밝은 불꽃이 흩어지고, 다시 맞닿을 때 작은 불꽃이 튄다. |
| 타격과 피격 | 승자는 남은 코인을 머리 위에서 한 장씩 다시 던진다. 사용한 코인의 면과 누적 위력은 다음 타격까지 남는다. 처치 타격은 별 모양 섬광과 황금 테두리로 표시한다. |
| 추가 공격 | 합이 모두 끝난 뒤 배정된 대원이 대기열에서 적에게 달려간다. 남은 대원은 자리를 유지하고, 다음 차례에 생존한 대상을 다시 확인한다. |
| 체력 | 각 토큰과 대기 대원의 이름 아래에 숫자가 든 체력 바를 둔다. 타격이 닿으면 색 막대가 즉시 줄고, 흰 막대가 0.25초 뒤부터 0.61초에 걸쳐 따라 줄어든다. |
| 정신력 | 교전 중인 아군과 적, 대기 대원의 체력 바 아래에 현재값을 표시한다. 합이 끝나면 현재값을 갱신하고 증감량을 잠깐 덧붙인다. |
| 전투 보상 | 승리 안내에서 동기화 수급과 자동 성장을 보여 준다. 일반 전투 뒤에는 콘셉트마다 제시된 팩에서 코스트 버튼 하나를 누른다. 영입 결과를 보여 준 뒤 운행을 이어 간다. |

합 점수는 기본 위력, 앞면 수와 코인 위력의 곱, 추가 합 위력, 높은 쪽에만 적용되는 공격 레벨 차이의 3분의 1 내림값, 최종 위력을 더한다. 피해는 공격 코인의 누적 위력에 물리·속성 내성 보정, 공격·방어 레벨 차이 보정, 합 교환 보정을 합한 배율을 곱한다. 99번 안에 판정이 끝나지 않은 쌍은 무승부로 처리한다. 이동과 전투 난수는 독립적이다.

기본 공격 레벨은 `캐릭터 레벨 + 공격`, 기본 방어 레벨은 `캐릭터 레벨 + 방어 × 2`다. 합에서는 공격 레벨이 9 높은 쪽에 위력 +3이 붙는다. 타격에서는 선택한 스킬의 공격 유형과 속성을 피해자의 내성과 대조하고, 공격 레벨과 방어 레벨 차이 `d`를 `d / (|d| + 25)`로 반영한다. 공격 유형은 참격·관통·타격이고 속성은 증기·서리·전류다. 내성 표시는 피해 보정치를 사용한다. 내성 ×0.75는 −12.5%, 약점 ×1.25는 +25%, 중립은 0%로 보인다. 후반 장갑 순찰기와 종착역 전환기의 앞면 코인 위력은 +3이다.

앞면 확률은 `50% + 정신력`이며 정신력의 범위는 −45~+45다. 최종 합 승자는 `8 + 2 × 합 횟수`만큼 정신력을 얻고 패자는 같은 양을 잃는다. 동점으로 다시 던진 횟수도 포함한다. 바뀐 정신력은 다음 공격 코인부터 적용되고 아군은 다음 전투에 이어서 사용한다.

`SkillBag`은 해금된 스킬을 1번 세 장, 2번 두 장, 3번 한 장의 비율로 뽑는다. 열린 카드를 모두 쓰면 채우고, 동기화로 새 스킬이 열리면 기존에 사용한 카드를 되돌리지 않고 새 슬롯의 카드만 추가한다. `Expedition`은 아군마다 가방을 보관한다. `Battle`은 교전에 스킬을 한 장 배정해 재토스와 후속 타격에 사용한다. `GameScreen`은 기술 세 개와 해금 상태를 표시한다. 스킬명 옆 코인 그림은 기본 코인 수를 뜻한다.

**5대2 테스트** 버튼은 주사위를 건너뛰고 고정 스킬로 한 라운드를 1배속으로 재생한다. 두 쌍의 합과 타격, 두 명의 동시 추가 공격, 마지막 한 명의 재지정 공격을 전장 위의 짧은 표시등 세 칸으로 보여 준다. 나령은 기본 위력 6과 코인 위력 +4를 사용하고 두 번 모두 앞면이 나오는 시드로 시작한다.

## 편성과 자동 성장

- 독립 대원은 24명이고 코스트 1~4에 각각 6명이 있다. 시작 코스트는 8·10·12 중에서 고르며 기본값은 10이다. 초기 대원 네 명은 중복 없이 뽑고 코스트 합을 정확히 맞춘다. 이후 출전은 살아 있는 대원 중 전투력 상위 5명이다.
- 일반 전투를 이기면 소속·공격 유형·공격 속성별로 팩 한 개씩 열린다. 팩 안에서 코스트를 고르면 두 조건을 모두 만족하는 대원 중 하나를 뽑는다. 타입과 속성 분류에는 각 대원의 첫 스킬을 기준으로 정한 대표 유형과 속성을 사용한다.
- 동기화 재료는 일반 승리와 보급에서 각각 1개, 중복 영입에서 2개다. 전투 및 정거장 정산 때 전투력 순으로 가장 높은 미완료 생존 대원에게 재료를 쓴다. 동기화 2에는 2개, 동기화 3에는 코스트 1~2 대원은 3개, 코스트 3~4 대원은 4개가 든다. 필요량이 모일 때까지 재료는 원정에 남는다.
- 동기화가 한 단계 오를 때마다 기본 위력과 코인 위력이 각각 1 오른다. 동기화 2에 2번 스킬, 동기화 3에 3번 스킬을 해금한다. 전투력은 공격 ×3, 현재 체력, 방어 ×2, 동기화 단계 상승당 5를 합한 값이다.
- 같은 세트에 속한 출전 대원 2명부터 시너지가 발동한다. 3명 이상이면 강화된다. 전투 시작 때 확정한 효과는 태그를 공유하는 대원에게 그 전투 동안 적용한다. 물리·속성은 1스킬 기준으로 분류한다.

`Skill.xlsx`에서 대원 능력치, 스킬, 종족·무기와 활성 세트를 편집한다. `sync-crew.ps1`은 이 값을 게임에 필요한 데이터로 변환하고, `crew.js`는 엑셀 ID에 초상과 기존 게임 식별자를 연결한다. `Expedition`은 편성·재료·팩을 관리한다. `Battle`은 전투 시작 시 계산된 세트 효과와 교전 중 표식·보호막·회복을 소유한다. `GameScreen`은 활성 세트와 실제 효과, 스킬의 추가 효과를 표시한다. 이동·전투·영입은 각자 시드 난수로 실행한다.

## 세트 시너지

모든 대원에게 소속과 물리 세트가 붙는다. 1코스트는 속성·동물·무기 중 하나가 추가되고 2~4코스트는 둘이 추가된다. 종족과 장비는 대원 콘셉트에 쓰이고, 전투에는 편성 화면에 표시되는 활성 세트가 적용된다. 예를 들어 나령·비아·안셀은 쥐 세트를 공유하고, 보라·카인은 총기 세트를 공유한다.

|---|---|---|
| Battle 전투팀 | 합 위력 +1 | 합 위력 +2 |
| Omega 서포트 팀 | 코인 앞면 확률 +5%p | 코인 앞면 확률 +10%p |
| Before 사전 준비 팀 | 첫 라운드 기본 위력 +1 | 첫 라운드 기본 위력 +2 |
| Detective 추적팀 | 첫 적중 표식 +1 | 첫 적중 표식 +2 |
| Nadir 뒷정리 팀 | 체력 절반 이하 적에게 타격당 피해 +2 | 타격당 피해 +3 |
| Clear 암살팀 | 일방 공격 기본 위력 +1 | 일방 공격 기본 위력 +2 |
| zenith 지원팀 | 전투 시작 보호막 3 | 전투 시작 보호막 5 |
| Alfa 간부 | 공격·방어 레벨 +2 | 공격·방어 레벨 +4 |
| 같은 물리 유형 | 공격 레벨 +2 | 공격 레벨 +3 |
| 같은 속성 | 방어 레벨 +2 | 방어 레벨 +3 |
| 같은 동물 | 코인 앞면 확률 +3%p | 코인 앞면 확률 +5%p |
| 같은 무기 | 해당 스킬 첫 적중 피해 +1 | 해당 스킬 첫 적중 피해 +2 |

앞면 확률은 정신력과 세트 효과를 더한 뒤 5~95% 사이로 제한한다. 표식은 같은 라운드에 다른 아군이 대상을 때리는 순간 한 번 소비된다. 두 표식이 겹치면 높은 값 하나를 사용한다. 스킬의 보호막과 회복은 첫 적중에 발동한다. 보호막은 자신에게 적용하며 남아 있는 수치와 새 수치 중 큰 값을 사용한다. 회복은 동시 타격이 끝난 후 살아 있는 아군 중 체력 비율이 가장 낮은 대원을 대상으로 한다. 게임은 마지막으로 동기화한 [대원 데이터](crew-data.js)를 읽는다.

## 래스터 이미지 생성

새 이미지 생성 프롬프트의 본문은 아래 문구를 그대로 붙여 끝낸다.

```text
ultra complexity, masterpiece, best quality, very aesthetic, detailed eyes, detailed hair, intricate details, soft shading, cinematic lighting, no text
```

내장 이미지 생성 도구에 설원 철도의 방한복, 남색 배경, 서리색과 황동색을 기본으로 지정했다. 모든 시트는 글자와 로고를 빼고 각 그림을 같은 크기의 정사각형에 배치했다.

초상화는 얼굴을 확대하고 굵은 윤곽과 넓은 색면으로 모자·머리·안경의 차이를 강조했다. 스킬 그림은 대표 장비와 한 줄의 동작 궤적을 중심으로 그렸고, 전투 아이콘은 강한 색 대비와 굵은 형태로 줄였다. 게임은 이 단순화 버전을 사용한다. 편성 목록의 초상화는 기본 64px, 스킬 그림은 50px, 능력치 아이콘은 22px로 표시한다.

- [대원과 적 초상화](assets/portraits-anime.png)는 3×3 시트다. 바루·배온·벤, 나령·노엘·지오, 순찰기·드론·전환기 순으로 가로줄을 구성한다.
- [바루·배온·벤 스킬](assets/skills-naru-ian-yul-simple.png)은 방패·차륜·차단기, 교차 궤적·신호등·야간 열차, 탄환·조준 렌즈·눈보라 관통을 그린 3×3 시트다.
- [나령·노엘·지오 스킬](assets/skills-seol-jin-onha-simple.png)은 전기 탐침·전격 타격·계전기, 신호봉·케이블 절단·송신탑, 안전핀·차단기 파쇄·구조 드릴을 그린 3×3 시트다.

### 전투 화면에서 구분할 요소

- 주인공은 청록빛 아군 실루엣, 위험은 산호색 적의 반동, 보상은 황동색 승리와 영입 표시다. 2초 안에 장비와 얼굴로 대원을 찾을 수 있게 한다.
- 익숙한 장비 요소는 항만 작업복과 접이식 도구를 쓴다. 팀 정체성은 옷의 기장과 장비를 드는 방식으로 드러낸다.

|---|---|---|
| 보호막 | 전투 초상 테두리에 청록 윤곽이 생기고 완전히 막은 타격에 흡수량이 뜬다 | 낮음 |

교전 중앙은 충돌과 코인을 위해 비워 두고, 보호막은 초상 윤곽에 붙인다. 기존 초상은 대원별 새 원화가 준비되는 순서대로 교체한다. 비아의 현재 게임 이미지는 고양이 귀 버전이며 새 원화는 쥐 귀를 기준으로 한다.

## 실행과 테스트

브라우저에서 `index.html`을 열고 **원정 시작** 또는 **5대2 테스트**를 누른다. 재생 속도는 상단에서 1×, 2×, 4×로 바꿀 수 있다. 정거장과 전투 결과 안내는 각 배속에서 같은 시간 동안 표시된다.

저장소 루트에서 `node --test prototypes/white-night-line/*.test.cjs`를 실행하면 전투 규칙과 화면 재생 로직을 검사한다.

### Skill.xlsx에서 밸런스 편집

PowerShell 7에서 저장소 루트를 열고 아래 명령을 한 번 실행한다. 기본 입력 파일은 현재 사용자의 바탕화면에 있는 `Skill.xlsx`다. 엑셀에서 저장하면 변환기가 `crew-data.js`를 갱신한다. 진행 중인 전투를 끝낸 다음 게임 브라우저를 새로고침하면 새 수치가 적용된다.

```powershell
& .\prototypes\white-night-line\sync-crew.ps1 -Watch
```

`-Watch`를 빼면 한 번만 동기화한다. 다른 사본을 사용하려면 `-Workbook 'C:\폴더\Skill.xlsx'`을 붙인다. 입력 오류가 있으면 PowerShell에 시트와 행이 표시되고 게임은 직전에 성공한 데이터를 읽는다.

- `캐릭터`의 **대원** 칸은 게임 이름이다. 캐릭터·스킬·컨셉 세 시트의 **ID**로 연결하므로 행의 순서나 대원 이름을 바꿔도 연결이 유지된다. 편집할 때 기존 ID를 유지한다.
- 체력, 레벨, 공격, 방어, 정신력, 내성·약점, 코스트와 스킬 수치는 엑셀 값을 사용한다. 공격 레벨, 방어 레벨, 전투력은 기본 능력치로 게임에서 계산한다.
- `스킬`의 Coin Basic과 Coin Value에는 각 스킬이 **처음 해금될 때**의 값을 입력한다. 동기화로 이후 단계가 열리면 기존 스킬의 기본 위력과 코인 위력이 1씩 오른다. Coin Count는 양의 정수다.
- 활성 세트 1은 소속, 2는 1스킬의 물리 유형에서 구한다. 활성 세트 3·4에는 대원의 속성·동물·무기 이름을 넣는다. 분류만 지정하려면 각각 `속성`, `동물`, `무기`로도 입력할 수 있다. 동물과 무기의 이름은 `컨셉`에서 읽는다.
- Plus에는 현재 정의된 효과 이름과 값을 입력한다. 예를 들어 `표식 +2 · 아군 회복 +3`을 쓸 수 있다. 새 효과나 팀 보너스의 발동 방식은 전투 규칙에서 정의한다.
